# 動画編集副業の税金はいくらから？確定申告・経費・源泉徴収を初心者向けに解説

動画編集は、在宅で始めやすい副業のひとつです。

YouTube動画、TikTok、Instagramリール、YouTubeショート、企業のPR動画などを編集して報酬を受け取る場合、利益が出ていれば税金の対象になることがあります。

この記事では、動画編集副業で収入が出た人向けに、確定申告が必要になる目安、経費にできるもの、源泉徴収、住民税、開業届の考え方を初心者向けにまとめます。

## 動画編集副業の収入は税金の対象になる？

動画編集副業で得た収入は、基本的に税金の対象になります。

たとえば、次のような報酬です。

* YouTube動画編集の報酬
* TikTok動画編集の報酬
* Instagramリール編集の報酬
* YouTubeショート編集の報酬
* 企業PR動画の編集報酬
* サムネイル作成の報酬
* テロップ入れの報酬
* カット編集の報酬
* BGM・効果音入れの報酬
* 動画広告制作の報酬
* SNS運用代行の一部としての動画編集報酬

会社員の副業として行っている場合でも、継続的に報酬を受け取っていれば、副業収入として記録しておく必要があります。

## 収入と所得の違い

税金では、受け取った報酬がそのまま税金の対象になるわけではありません。

基本的には、次のように計算します。

```text
収入 - 経費 = 所得
```

たとえば、動画編集で年間40万円の報酬があり、編集ソフト、素材サイト、通信費などに12万円かかった場合、所得は28万円です。

```text
収入40万円 - 経費12万円 = 所得28万円
```

確定申告が必要かどうかを考えるときは、収入ではなく所得を確認します。

## 会社員は動画編集の所得が20万円を超えると確定申告が必要？

会社員やパートなどで給与をもらっている人は、動画編集副業などの所得が年間20万円を超えると、所得税の確定申告が必要になる可能性があります。

ここでいう20万円は、売上や報酬額ではなく所得です。

| 動画編集の年間収入 | 経費 | 所得 | 確定申告の目安 |
| ---: | ---: | ---: | --- |
| 10万円 | 4万円 | 6万円 | 所得税の確定申告は不要な可能性あり |
| 30万円 | 12万円 | 18万円 | 所得税の確定申告は不要な可能性あり |
| 50万円 | 15万円 | 35万円 | 確定申告が必要になる可能性あり |

ただし、医療費控除、ふるさと納税、住宅ローン控除の初年度などで確定申告をする場合は、動画編集副業の所得も一緒に申告する必要があります。

また、所得税の確定申告が不要でも、住民税の申告が必要になる場合があります。

## 動画編集副業は雑所得？事業所得？

動画編集副業の所得区分は、主に次のどちらかになることが多いです。

| 所得区分 | 目安 |
| --- | --- |
| 雑所得 | 会社員の副業として小規模に受けている |
| 事業所得 | 継続的に案件を受け、事業として運営している |

たとえば、会社員が空き時間に月1〜2件だけ動画編集を受けている程度なら、雑所得として考えるケースが多いです。

一方で、複数のクライアントと契約し、毎月継続して報酬があり、請求書を発行して帳簿をつけている場合は、事業所得になる可能性もあります。

どちらになるかは、収入の規模、継続性、事業としての実態、帳簿の有無などで判断されます。

迷う場合は、税務署や税理士に確認した方が安心です。

## 動画編集副業の主な収入パターン

動画編集副業には、いくつかの収入パターンがあります。

| 収入の種類 | 内容 |
| --- | --- |
| 単発編集 | 動画1本ごとに報酬を受け取る |
| 月額契約 | 毎月決まった本数を編集して固定報酬を受け取る |
| SNSショート動画制作 | TikTok、リール、ショート動画を制作する |
| サムネイル作成 | YouTube用サムネイルを制作する |
| 台本・構成込み | 動画の企画や構成も含めて受ける |
| 撮影込み | 撮影から編集までまとめて受ける |
| SNS運用代行込み | 投稿作成、動画編集、分析まで担当する |
| クラウドソーシング案件 | ココナラ、クラウドワークス、ランサーズなどで受ける |

同じ動画編集でも、編集だけなのか、企画・台本・サムネイル・投稿管理まで含むのかで、収入や経費の内容が変わります。

## 業務委託の報酬はどう記録する？

動画編集副業は、業務委託として受けることが多いです。

報酬を受け取ったら、次の内容を記録しておきましょう。

* クライアント名
* 案件内容
* 動画本数
* 請求日
* 入金日
* 請求額
* 源泉徴収の有無
* 振込手数料の負担
* 消費税の有無
* 使用した編集ソフトや素材

月額契約の場合は、毎月の請求額と入金額を分けて管理するとわかりやすいです。

単発案件の場合も、案件ごとに記録しておくと後から確認しやすくなります。

## 源泉徴収されている場合はどうする？

動画編集の報酬は、契約内容によっては源泉徴収されて入金されることがあります。

たとえば、請求額が5万円でも、実際の入金額がそれより少ないケースです。

| 項目 | 金額例 |
| --- | ---: |
| 請求額 | 50,000円 |
| 源泉徴収税額 | 5,105円 |
| 入金額 | 44,895円 |

この場合、入金額だけでなく、源泉徴収前の報酬額も確認しておきましょう。

動画編集の報酬が常に源泉徴収の対象になるとは限りません。

ただし、企画、原稿作成、デザイン、出演、講演、著作物の使用などが関係する案件では、源泉徴収の対象になるか確認が必要です。

確定申告では、源泉徴収された税額を反映することで、払いすぎた税金が戻る場合もあります。

支払調書が届くこともありますが、届かない場合でも、自分で請求額、入金額、源泉徴収額を記録しておくことが大切です。

動画編集副業では、収入を得るために必要だった支出は経費にできる可能性があります。

代表的なものは次のとおりです。

| 経費の例 | 内容 |

| スマホ代の一部 | クライアント連絡、確認、撮影補助に使う場合 |

大切なのは、「動画編集の収入を得るために必要だった」と説明できることです。

私用でも使っているものは、全額ではなく、仕事に使った分だけを経費にする考え方になります。

## AdobeやCanvaなどのソフト代は経費にできる？

動画編集で使うAdobe Premiere Pro、After Effects、Photoshop、Canva Proなどは、業務に使っている場合、経費にできる可能性があります。

たとえば、次のような支出です。

* Adobe Creative Cloud
* Adobe Premiere Pro
* Adobe After Effects
* Photoshop
* Illustrator
* Canva Pro
* CapCut Pro
* Final Cut Pro
* DaVinci Resolve Studio
* 有料BGMサイト
* 有料素材サイト

ただし、趣味や私用でも使っている場合は、仕事で使っている割合に応じて按分する考え方になります。

たとえば、Adobe代が月6,000円で、8割を動画編集副業、2割を私用で使っているなら、経費にする金額は月4,800円です。

```text
6,000円 x 80% = 4,800円
```

割合は適当に決めるのではなく、自分で説明できる基準にしておきましょう。

## パソコンや機材は全額経費にできる？

動画編集用にパソコン、モニター、外付けSSDなどを購入した場合、経費にできる可能性があります。

ただし、私用でも使っている場合は、全額を経費にするのではなく、動画編集で使った分だけを按分します。

たとえば、20万円のパソコンを購入し、動画編集副業で使う割合が70%なら、動画編集分として考える金額は14万円です。

```text
20万円 x 70% = 14万円
```

また、高額なパソコンや機材は、購入した年に全額を経費にできるとは限らず、減価償却が関係する場合があります。

金額が大きい機材を買った場合は、会計ソフトや税理士相談を使うと安心です。

## スマホ代や通信費は全額経費にできる？

動画編集副業では、クライアントとの連絡、素材のダウンロード、動画の納品などでインターネットを使います。

そのため、通信費を経費にできる可能性があります。

ただし、プライベートでも使っている場合は、全額を経費にするのではなく、仕事で使った分だけを按分します。

たとえば、インターネット代が月5,000円で、動画編集副業で使っている割合を40%と考えるなら、経費にする金額は月2,000円です。

```text
5,000円 x 40% = 経費2,000円
```

スマホ代も同じ考え方です。

業務で使った割合を説明できるようにしておきましょう。

## クラウドソーシング経由の報酬はどうする？

動画編集副業は、ココナラ、クラウドワークス、ランサーズなどで受けることもあります。

クラウドソーシング経由でも、報酬は収入として記録する必要があります。

また、サービス手数料が差し引かれて入金される場合があります。

この場合は、売上、手数料、入金額を分けて確認しましょう。

| 項目 | 金額例 |
| --- | ---: |
| 案件報酬 | 30,000円 |
| サービス手数料 | 6,000円 |
| 実際の入金額 | 24,000円 |

サービス手数料は、販売や受注のためにかかった費用として経費にできる可能性があります。

入金額だけを見ると収入を少なく見積もってしまうことがあるため、管理画面の明細を保存しておきましょう。

## 外注費がある場合は注意

動画編集案件が増えてくると、作業の一部を外注することがあります。

たとえば、次のような外注です。

* サムネイル制作を外注した
* テロップ入れを外注した
* BGM選定を外注した
* カット編集を外注した
* 一部の動画編集を別の編集者に依頼した

外注費は、業務に必要な費用として経費にできる可能性があります。

ただし、誰に、何を、いくらで依頼したのかを記録しておきましょう。

請求書、領収書、支払い履歴、チャットでの依頼内容などを残しておくと安心です。

## 住民税にも注意

会社員の場合、副業所得が20万円以下なら、所得税の確定申告が不要になるケースがあります。

ただし、住民税は別です。

動画編集副業で所得が出ている場合、住民税の申告が必要になることがあります。

また、会社に副業を知られたくない人は、住民税の納付方法にも注意が必要です。

住民税の扱いは自治体によって異なるため、不安な場合は住んでいる市区町村の窓口や公式サイトで確認しましょう。

## 開業届は必要？

動画編集副業を始めたからといって、必ずすぐに開業届が必要になるわけではありません。

趣味や副業として小さく始めた段階では、まず収入と経費の記録を整えることが優先です。

一方で、次のような場合は開業届を検討してもよいでしょう。

* 継続的に案件を受けている
* 複数のクライアントがいる
* 毎月安定した収入がある
* 請求書を発行している
* 事業として育てたい
* 青色申告を使いたい

青色申告を使うには、原則として事前の届出が必要です。

節税面でメリットがある一方、帳簿づけの手間も増えるため、収入規模に合わせて考えましょう。

## インボイス登録は必要？

動画編集副業をしている個人が、必ずインボイス登録しなければならないわけではありません。

ただし、動画編集は法人や個人事業主のクライアントから仕事を受けることが多いため、取引先からインボイス対応を求められる可能性があります。

特に、次のような場合は確認が必要です。

* 法人クライアントが多い
* 継続契約をしている
* 請求書を毎月発行している
* 消費税額を記載した請求書を求められる
* 今後、事業として拡大したい

ただし、インボイス登録をすると、消費税の申告が関係してくることがあります。

副業規模が小さいうちは、勢いで登録せず、取引先の要望、売上規模、今後の方針を確認してから判断しましょう。

## 動画編集副業の税金でよくある勘違い

### 報酬が手渡しなら申告しなくていい？

手渡しでも銀行振込でも、収入があることに変わりはありません。

報酬を受け取ったら、日付、相手、金額、内容を記録しておきましょう。

### クラウドソーシング経由なら記録しなくていい？

クラウドワークス、ランサーズ、ココナラなどを経由した場合でも、報酬は収入として記録する必要があります。

サービス手数料も確認し、経費として整理しましょう。

### 源泉徴収されていれば確定申告はいらない？

源泉徴収されていても、確定申告が必要になる場合があります。

また、確定申告をすることで、源泉徴収された税金の一部が戻ることもあります。

### 売上が20万円以下なら何もしなくていい？

20万円で見るのは、売上ではなく所得です。

また、所得税の確定申告が不要でも、住民税の申告が必要になる場合があります。

### Adobeやパソコン代は全部経費にできる？

業務専用なら経費として説明しやすいですが、私用でも使っている場合は按分が必要です。

高額なパソコンや機材は、減価償却が関係する場合もあります。

## 動画編集副業を始めたらやること

動画編集副業で報酬が出始めたら、次の流れで整理するとわかりやすいです。

1. クライアントごとに報酬を記録する
2. 請求書と入金日を管理する
3. 源泉徴収の有無を確認する
4. Adobe、Canva、素材サイト、通信費などの経費を記録する
5. 業務委託契約書や依頼文を保存する
6. 年間の所得を計算する
7. 所得が20万円を超えるか確認する
8. 住民税の申告が必要か確認する
9. 案件が増えてきたら会計ソフトや税理士相談を検討する

動画編集副業は、ソフト代や素材代などの経費が発生しやすい副業です。

早めに記録の習慣を作っておくと、確定申告の時期に慌てにくくなります。
