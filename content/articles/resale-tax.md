# せどり・転売の税金はいくらから？確定申告が必要なケースを初心者向けに解説

メルカリ、Amazon、楽天、ヤフオク、ラクマなどを使って、せどり・転売をしている人は少なくありません。

ただ、利益が出てくると気になるのが税金です。

「不用品を売っているだけなら税金はかからない？」
「仕入れて売っている場合は確定申告が必要？」
「会社員の副業なら20万円まで大丈夫？」

このあたりは、少し混乱しやすい部分です。

この記事では、せどり・転売をしている人向けに、税金がかかるケース、確定申告が必要になる目安、経費にできるもの、在庫管理の注意点をわかりやすくまとめます。

## せどり・転売の利益は税金の対象になる？

せどり・転売で利益が出た場合、その利益は税金の対象になる可能性があります。

特に、次のような場合は「販売目的の副業」と見られやすいです。

* 安く仕入れて高く売っている
* 継続的に商品を販売している
* 複数の商品をまとめて仕入れている
* 利益を出す目的で販売している
* フリマアプリやECサイトで定期的に販売している
* 在庫を持って販売している

このような場合は、単なる不用品販売ではなく、副業収入として考えた方がよいです。

## 不用品販売とせどり・転売の違い

税金でまず分けて考えたいのが、「不用品販売」と「せどり・転売」です。

| 区分 | 内容 | 税金の考え方 |
| --- | --- | --- |
| 不用品販売 | 自分が使っていた服、家具、家電などを売る | 原則として課税されないことが多い |
| せどり・転売 | 売る目的で仕入れて販売する | 利益が出ると課税対象になりやすい |

たとえば、自分が着なくなった服や使わなくなった家具を売るだけなら、生活用動産の売却として、税金がかからないケースが多いです。

一方で、利益を出す目的で商品を仕入れて販売している場合は、税金の対象になる可能性が高くなります。

## 売上と所得の違い

せどり・転売では、売上がそのまま税金の対象になるわけではありません。

税金では、基本的に「所得」で考えます。

```text
売上 − 経費 = 所得
```

たとえば、年間100万円売れたとしても、仕入れ代や送料、販売手数料などに80万円かかっていれば、所得は20万円です。

```text
売上100万円 − 経費80万円 = 所得20万円
```

確定申告が必要かどうかを考えるときは、売上ではなく所得を確認します。

## 会社員はせどりの所得が20万円を超えると確定申告が必要？

会社員やパートなどで給与をもらっている人は、せどり・転売などの副業所得が年間20万円を超えると、所得税の確定申告が必要になる可能性があります。

ここでいう20万円は、売上ではなく所得です。

| 年間売上 | 経費 | 所得 | 確定申告の目安 |
| ---: | ---: | ---: | --- |
| 30万円 | 25万円 | 5万円 | 所得税の確定申告は不要な可能性あり |
| 80万円 | 65万円 | 15万円 | 所得税の確定申告は不要な可能性あり |
| 120万円 | 85万円 | 35万円 | 確定申告が必要になる可能性あり |

ただし、医療費控除、ふるさと納税、住宅ローン控除の初年度などで確定申告をする場合は、せどり・転売の所得も一緒に申告する必要があります。

また、所得税の確定申告が不要でも、住民税の申告が必要になる場合があります。

## せどり・転売は雑所得？事業所得？

せどり・転売の所得区分は、主に次のどちらかになることが多いです。

| 所得区分 | 目安 |
| --- | --- |
| 雑所得 | 副業として小規模に行っている |
| 事業所得 | 継続的に販売し、事業として運営している |

たとえば、会社員が空き時間に少しだけ仕入れて販売している場合は、雑所得として考えるケースが多いです。

一方で、毎月継続して仕入れを行い、在庫を管理し、帳簿をつけて本格的に販売している場合は、事業所得になる可能性もあります。

どちらになるかは、販売の継続性、利益の規模、帳簿の有無、事業としての実態などで判断されます。

迷う場合は、税務署や税理士に確認した方が安心です。

## せどり・転売で経費にできるもの

せどり・転売では、販売のために必要だった支出は経費にできる可能性があります。

代表的なものは次のとおりです。

| 経費の例 | 内容 |
| --- | --- |
| 仕入れ代 | 販売する商品の購入費 |
| 送料 | 商品の発送費、仕入れ時の送料 |
| 販売手数料 | メルカリ、Amazon、ヤフオクなどの手数料 |
| 梱包資材 | 段ボール、封筒、緩衝材、テープなど |
| 保管用品 | 商品保管用の棚、ケースなど |
| 撮影用品 | 商品写真用の背景紙、ライト、小物など |
| 交通費 | 仕入れのための移動費 |
| 通信費の一部 | 出品・連絡・販売管理に使った分 |
| スマホ・パソコン代の一部 | 販売作業に使っている場合 |
| 会計ソフト代 | 売上や経費の管理に使う費用 |

ポイントは、「せどり・転売のために使った」と説明できるかどうかです。

私用でも使っているものは、全額ではなく、仕事に使った分だけを経費にする考え方になります。

## 仕入れ代は全部その年の経費になる？

せどり・転売で注意したいのが、仕入れ代の扱いです。

仕入れた商品がすべてすぐに経費になるわけではありません。

年末時点で売れていない商品は、在庫として残ります。

ざっくり言うと、売れた商品に対応する仕入れ代が、その年の経費になります。

たとえば、次のようなケースです。

| 内容 | 金額 |
| --- | ---: |
| 1年間の仕入れ | 50万円 |
| 年末時点で残っている在庫 | 15万円 |
| その年に経費として考える仕入れ分 | 35万円 |

このように、年末に残っている在庫がある場合は、仕入れ代をそのまま全額経費にできるとは限りません。

商品数が増えてきたら、在庫表を作って管理しておくと安心です。

## せどり・転売の所得計算例

会社員が副業でせどりをしている例で考えます。

| 項目 | 金額 |
| --- | ---: |
| 年間売上 | 1,200,000円 |
| 売れた商品の仕入れ代 | 750,000円 |
| 送料 | 90,000円 |
| 販売手数料 | 100,000円 |
| 梱包資材 | 20,000円 |
| 交通費 | 30,000円 |
| 所得 | 210,000円 |

この場合、所得は次のように計算します。

```text
1,200,000円 − 990,000円 = 210,000円
```

所得が20万円を超えているため、会社員の副業であれば確定申告が必要になる可能性があります。

## 住民税にも注意

会社員の場合、副業所得が20万円以下なら、所得税の確定申告が不要になるケースがあります。

ただし、住民税は別です。

せどり・転売で所得が出ている場合、住民税の申告が必要になることがあります。

また、会社に副業を知られたくない人は、住民税の納付方法にも注意が必要です。

住民税の扱いは自治体によって異なるため、不安な場合は住んでいる市区町村の窓口や公式サイトで確認しましょう。

## 古物商許可が必要になることもある

せどり・転売では、税金とは別に「古物商許可」が関係することがあります。

中古品を仕入れて、利益を出す目的で継続的に販売する場合は、古物商許可が必要になる可能性があります。

たとえば、次のようなケースです。

* 中古品を仕入れて販売する
* リサイクルショップで買った商品を転売する
* フリマアプリで仕入れた中古品を販売する
* 中古ブランド品や中古家電を継続的に販売する

古物商許可は税金ではなく、警察署の管轄です。

中古品を扱う場合は、税金だけでなく古物営業法の確認も必要です。

## せどり・転売で残しておきたい記録

せどり・転売をしている人は、次の記録を残しておくと確定申告のときに楽になります。

| 残すもの | 理由 |
| --- | --- |
| 売上明細 | 年間売上を確認するため |
| 仕入れ時のレシート・領収書 | 仕入れ代を証明するため |
| 販売手数料の記録 | 経費として整理するため |
| 送料の記録 | 発送費用を確認するため |
| 梱包資材のレシート | 経費の証拠になるため |
| 在庫表 | 年末時点の在庫を確認するため |
| 入金明細 | 実際の入金額を確認するため |

特に、せどり・転売では仕入れと在庫の管理が大切です。

商品数が少ないうちはスプレッドシートでも十分です。

## せどり・転売の税金でよくある勘違い

### 売上が20万円以下なら申告不要？

20万円で見るのは、売上ではなく所得です。

売上が50万円でも、経費が40万円なら所得は10万円です。

逆に、売上が25万円でも、経費がほとんどなければ所得が20万円を超えることがあります。

### 不用品販売なら全部非課税？

自分が使っていた生活用品を売るだけなら、税金がかからないケースが多いです。

ただし、貴金属、宝石、書画、骨とうなどで高額なものは課税対象になる場合があります。

また、売る目的で仕入れている場合は、不用品販売とは考え方が違います。

### フリマアプリだから税務署にバレない？

フリマアプリやECサイトを使っている場合でも、売上や入金の記録は残ります。

継続的に利益が出ているなら、最初から記録しておく方が安全です。

### 赤字なら何もしなくていい？

赤字でも、売上や仕入れ、在庫の記録は残しておきましょう。

特に翌年以降も販売を続ける場合、過去の記録があると所得計算がしやすくなります。

## せどり・転売を始めたらやること

せどり・転売を始めたら、次の流れで整理するとわかりやすいです。

1. 売上を月ごとに記録する
2. 仕入れ代を商品ごとに記録する
3. 送料、手数料、梱包資材を記録する
4. 年末時点の在庫を確認する
5. 年間の所得を計算する
6. 所得が20万円を超えるか確認する
7. 住民税の申告が必要か確認する
8. 中古品を継続販売する場合は古物商許可も確認する

せどり・転売は、売上だけを見ると大きく見えやすい副業です。

しかし、仕入れ代や送料、手数料を引くと、実際の所得は思ったより少ないこともあります。

だからこそ、売上だけでなく、仕入れと経費を分けて記録することが大切です。

## まとめ

せどり・転売で利益が出た場合、その利益は税金の対象になる可能性があります。

会社員の副業として行っている場合、年間所得が20万円を超えると、所得税の確定申告が必要になる可能性があります。

判断するのは売上ではなく所得です。

```text
売上 − 経費 = 所得
```

また、不用品販売と、利益目的で仕入れて売るせどり・転売は考え方が違います。

自分で使っていた生活用品を売るだけなら非課税になるケースが多いですが、販売目的で仕入れている場合は税金の対象になりやすいです。

まずは、売上、仕入れ代、送料、販売手数料、在庫を記録するところから始めましょう。
