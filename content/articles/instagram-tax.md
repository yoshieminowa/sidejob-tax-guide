# Instagram副業の税金はいくらから？PR案件・アフィリエイト・商品提供の確定申告を解説

Instagramで副業を始める人が増えています。

たとえば、PR案件、アフィリエイト、商品紹介、リール投稿、ショップ誘導、デジタル商品の販売などです。

最初は趣味の延長でも、収入が発生すると税金の対象になることがあります。

この記事では、Instagram副業で収入が出たときに、確定申告が必要になる目安、経費にできるもの、商品提供を受けた場合の注意点、住民税の考え方をわかりやすくまとめます。

## Instagram副業の収入は税金の対象になる？

Instagramを使って得た収入は、基本的に税金の対象になります。

たとえば、次のような収入です。

* PR案件の報酬
* アフィリエイト報酬
* 商品紹介による紹介料
* リールや動画投稿に関する収益
* 企業案件の報酬
* 投稿作成の代行報酬
* SNS運用代行の報酬
* 自分の商品やサービス販売による売上
* note、Kindle、PDF教材などへの誘導による売上
* オンライン講座や相談サービスの売上

Instagramそのものから直接お金を受け取っていなくても、Instagramをきっかけに収入が発生していれば、副業収入として考える必要があります。

## 売上と所得の違い

税金では、売上がそのまま税金の対象になるわけではありません。

基本的には、次のように計算します。

```text
売上 − 経費 = 所得
```

たとえば、Instagram副業で年間30万円の収入があり、撮影小物、通信費、編集アプリ、交通費などに8万円かかった場合、所得は22万円です。

```text
売上30万円 − 経費8万円 = 所得22万円
```

確定申告が必要かどうかを考えるときは、売上ではなく所得を確認します。

## 会社員はInstagram副業の所得が20万円を超えると確定申告が必要？

会社員やパートなどで給与をもらっている人は、Instagram副業などの所得が年間20万円を超えると、所得税の確定申告が必要になる可能性があります。

ここでいう20万円は、売上ではなく所得です。

| Instagram副業の年間収入 | 経費 | 所得 | 確定申告の目安 |
| ---: | ---: | ---: | --- |
| 5万円 | 1万円 | 4万円 | 所得税の確定申告は不要な可能性あり |
| 25万円 | 8万円 | 17万円 | 所得税の確定申告は不要な可能性あり |
| 40万円 | 10万円 | 30万円 | 確定申告が必要になる可能性あり |

ただし、医療費控除、ふるさと納税、住宅ローン控除の初年度などで確定申告をする場合は、Instagram副業の所得も一緒に申告する必要があります。

また、所得税の確定申告が不要でも、住民税の申告が必要になる場合があります。

## Instagram副業は雑所得？事業所得？

Instagram副業の所得区分は、主に次のどちらかになることが多いです。

| 所得区分 | 目安 |
| --- | --- |
| 雑所得 | 趣味や副業として小規模に収入を得ている |
| 事業所得 | 継続的に収益化し、事業として運営している |

たとえば、会社員が休日に投稿し、たまにPR案件やアフィリエイト報酬がある程度なら、雑所得として考えるケースが多いです。

一方で、継続的に案件を受けている、請求書を発行している、帳簿をつけている、SNS運用を仕事として受けている場合は、事業所得になる可能性もあります。

どちらになるかは、収入の規模、継続性、事業としての実態、帳簿の有無などで判断されます。

迷う場合は、税務署や税理士に確認した方が安心です。

## Instagram副業の主な収入パターン

Instagram副業といっても、収入の形はいくつかあります。

| 収入の種類 | 内容 |
| --- | --- |
| PR案件 | 企業の商品やサービスを投稿で紹介して報酬を受け取る |
| アフィリエイト | 紹介リンク経由で購入や登録があると報酬が入る |
| 商品提供 | 商品を無償で受け取り、投稿で紹介する |
| SNS運用代行 | 企業や個人のInstagram運用を代行する |
| 投稿作成代行 | 画像、リール、キャプションなどを制作する |
| 自分の商品販売 | ハンドメイド、テンプレート、PDF、講座などを売る |
| ブログ・note誘導 | Instagramから外部サイトへ誘導して収益化する |

同じInstagram副業でも、収入の種類によって記録すべき内容が少し変わります。

## PR案件の報酬は税金の対象になる？

PR案件で報酬を受け取った場合、その報酬は税金の対象になります。

たとえば、次のようなケースです。

* 1投稿あたり1万円の報酬を受け取った
* リール動画1本で3万円の報酬を受け取った
* ストーリーズ投稿で報酬を受け取った
* 商品紹介と引き換えに固定報酬を受け取った
* 成果報酬型のPR案件で報酬が入った

銀行振込、ポイント、電子マネー、ギフト券など、受け取り方が現金以外でも、実質的に報酬であれば記録しておいた方が安全です。

## アフィリエイト報酬も税金の対象になる？

Instagramのプロフィールリンクやストーリーズ、ブログへの誘導などでアフィリエイト報酬が発生した場合も、税金の対象になります。

たとえば、次のような収入です。

* 楽天ROOMや楽天アフィリエイトの報酬
* Amazonアソシエイトの報酬
* ASP経由の成果報酬
* 美容、転職、金融、通信サービスなどの紹介報酬
* ブログへ誘導して発生した広告収入

アフィリエイトは少額から始まりやすいですが、報酬が積み上がると年間で大きな金額になることがあります。

月ごとの発生額と入金額を記録しておきましょう。

## 商品提供を受けた場合は税金がかかる？

Instagramでは、企業から商品提供を受けて投稿することがあります。

商品提供は、現金を受け取っていなくても、案件の条件や商品の内容によっては経済的な利益として考える必要が出てくる場合があります。

特に、次のようなケースは注意が必要です。

* 投稿することを条件に商品を受け取った
* 高額な商品を提供された
* 継続的に商品提供を受けている
* 商品提供に加えて報酬も受け取っている
* 受け取った商品を後で販売している

一方で、単なるサンプル提供や少額の商品提供など、扱いが判断しにくいケースもあります。

商品提供を受けたら、少なくとも次の内容は記録しておくと安心です。

* 提供元の企業名
* 商品名
* おおよその価格
* 受け取った日
* 投稿条件の有無
* 報酬の有無

現金ではないから記録しなくてよい、と考えない方が安全です。

## Instagram副業で経費にできるもの

Instagram副業では、収入を得るために必要だった支出は経費にできる可能性があります。

代表的なものは次のとおりです。

| 経費の例 | 内容 |
| --- | --- |
| 撮影小物 | 背景紙、布、小物、装飾品など |
| 撮影機材 | ライト、三脚、スマホスタンド、カメラなど |
| 編集アプリ | Canva、CapCut、Adobe系ツールなど |
| 有料素材 | 写真素材、フォント、テンプレートなど |
| 通信費の一部 | 投稿、連絡、管理に使ったインターネット代 |
| スマホ代の一部 | 撮影や投稿管理に使っている場合 |
| パソコン・タブレット代の一部 | 画像編集や案件管理に使っている場合 |
| 交通費 | 撮影や取材のための移動費 |
| カフェ代の一部 | 打ち合わせなど業務目的の場合 |
| 書籍・セミナー代 | SNS運用や撮影、マーケティング学習に使ったもの |
| 会計ソフト代 | 売上や経費を管理するための費用 |

大切なのは、「Instagram副業の収入を得るために必要だった」と説明できることです。

私用でも使っているものは、全額ではなく、仕事に使った分だけを経費にする考え方になります。

## 美容・コスメ・服は経費にできる？

Instagram副業では、美容、コスメ、ファッション系の発信をしている人も多いです。

この場合、コスメや服を経費にできるかが気になると思います。

結論としては、投稿や案件のために購入したものなら、経費にできる可能性はあります。

ただし、私生活でも使えるものは、経費として説明しにくい場合があります。

| 支出 | 経費になりやすさ |
| --- | --- |
| PR投稿用に購入した撮影小物 | 比較的説明しやすい |
| 商品レビュー用に購入したコスメ | 投稿内容と記録があれば説明しやすい |
| 普段も着る服 | 私用との区別が難しい |
| 日常的に使うスキンケア用品 | 私用との区別が難しい |
| 撮影専用の背景布やライト | 比較的説明しやすい |

判断のポイントは、「その支出が収入につながる活動のためだった」と説明できるかどうかです。

投稿URL、案件内容、購入日、レシートをセットで残しておくと整理しやすくなります。

## スマホ代や通信費は全額経費にできる？

Instagram副業ではスマホやインターネットを使うため、通信費を経費にできる可能性があります。

ただし、プライベートでも使っている場合は、全額を経費にするのではなく、仕事で使った分だけを按分する考え方になります。

たとえば、スマホ代が月1万円で、Instagram副業で使っている割合を30％と考えるなら、経費にする金額は月3,000円です。

```text
スマホ代1万円 × 30％ = 経費3,000円
```

割合は適当に決めるのではなく、自分で説明できる基準にしておきましょう。

## Instagram副業の所得計算例

会社員がInstagram副業で収入を得た場合の例です。

| 項目 | 金額 |
| --- | ---: |
| PR案件の報酬 | 180,000円 |
| アフィリエイト報酬 | 120,000円 |
| 合計収入 | 300,000円 |
| 撮影小物 | 20,000円 |
| 編集アプリ | 12,000円 |
| 通信費の一部 | 36,000円 |
| 交通費 | 8,000円 |
| 経費合計 | 76,000円 |
| 所得 | 224,000円 |

この場合、所得は次のように計算します。

```text
300,000円 − 76,000円 = 224,000円
```

会社員の副業としてこの所得が出ている場合、確定申告が必要になる可能性があります。

## 源泉徴収されている場合はどうする？

企業案件では、報酬から源泉徴収されて入金されることがあります。

たとえば、報酬額が3万円でも、実際の入金額がそれより少ないケースです。

この場合、入金額だけでなく、源泉徴収前の報酬額も確認しておきましょう。

確定申告では、源泉徴収された税額を反映することで、払いすぎた税金が戻る場合もあります。

企業から支払調書が届くこともありますが、届かない場合でも自分で報酬額と源泉徴収額を記録しておくことが大切です。

## Instagram副業で住民税に注意

会社員の場合、副業所得が20万円以下なら、所得税の確定申告が不要になるケースがあります。

ただし、住民税は別です。

Instagram副業で所得が出ている場合、住民税の申告が必要になることがあります。

また、会社に副業を知られたくない人は、住民税の納付方法にも注意が必要です。

住民税の扱いは自治体によって異なるため、不安な場合は、住んでいる市区町村の窓口や公式サイトで確認しましょう。

## Instagram副業で開業届は必要？

Instagram副業を始めたからといって、必ずすぐに開業届が必要になるわけではありません。

趣味や副業として小さく始めた段階では、まず売上と経費の記録を整えることが優先です。

一方で、次のような場合は開業届を検討してもよいでしょう。

* 継続的に企業案件を受けている
* 毎月安定した収入がある
* SNS運用代行を仕事として受けている
* 請求書を発行している
* 事業として育てたい
* 青色申告を使いたい

青色申告を使うには、原則として事前の届出が必要です。

節税面でメリットがある一方、帳簿づけの手間も増えるため、収入規模に合わせて考えましょう。

## Instagram副業でインボイス登録は必要？

Instagram副業をしている個人が、必ずインボイス登録しなければならないわけではありません。

個人向けの発信やアフィリエイト中心なら、インボイス登録が不要なケースもあります。

一方で、企業からPR案件やSNS運用代行を受けている場合、取引先からインボイス対応を求められる可能性があります。

ただし、インボイス登録をすると、消費税の申告が関係してくることがあります。

副業規模が小さいうちは、勢いで登録せず、取引先の要望、売上規模、今後の方針を確認してから判断しましょう。

## Instagram副業で残しておきたい記録

Instagram副業をしている人は、次の記録を残しておくと確定申告のときに楽になります。

| 残すもの | 理由 |
| --- | --- |
| 案件報酬の明細 | 収入額を確認するため |
| 銀行口座の入金履歴 | 実際の入金を確認するため |
| アフィリエイト管理画面の報酬明細 | 発生報酬と確定報酬を確認するため |
| 源泉徴収額の記録 | 確定申告で必要になる場合があるため |
| 商品提供の記録 | 現金以外の利益を整理するため |
| 領収書・レシート | 経費の証拠になるため |
| 投稿URLや案件内容 | 何のための支出か説明しやすくするため |
| 請求書・契約書 | 企業案件の内容を確認するため |

特に、PR案件や商品提供は、後から内容を思い出しにくいです。

案件ごとに、報酬、商品提供、投稿日、投稿URLをメモしておくと整理しやすくなります。

## Instagram副業の税金でよくある勘違い

### フォロワーが少なければ税金は関係ない？

税金はフォロワー数ではなく、収入や所得で考えます。

フォロワーが少なくても、PR案件やアフィリエイト報酬で利益が出ていれば、税金の対象になる可能性があります。

### 商品提供だけなら申告しなくていい？

現金を受け取っていなくても、投稿条件付きの商品提供や高額商品の提供は、経済的な利益として考える必要が出る場合があります。

判断に迷う場合は、税務署や税理士に確認しましょう。

### 売上が20万円以下なら何もしなくていい？

20万円で見るのは、売上ではなく所得です。

また、所得税の確定申告が不要でも、住民税の申告が必要になる場合があります。

### スマホ代は全部経費にできる？

Instagram副業で使っていても、私用でも使うスマホ代を全額経費にするのは説明しにくいです。

仕事で使った割合に応じて按分する考え方になります。

### 案件でもらったギフト券は収入にならない？

ギフト券やポイントでも、実質的に報酬として受け取っている場合は、収入として考える必要があります。

現金以外でも記録しておきましょう。

## Instagram副業を始めたらやること

Instagram副業を始めたら、次の流れで整理するとわかりやすいです。

1. PR案件、アフィリエイト、商品販売など収入の種類を分ける
2. 月ごとの収入を記録する
3. 撮影小物、編集アプリ、通信費などの経費を記録する
4. 商品提供を受けた場合は内容をメモする
5. 年間の所得を計算する
6. 所得が20万円を超えるか確認する
7. 住民税の申告が必要か確認する
8. 案件が増えてきたら会計ソフトや税理士相談を検討する

Instagram副業は、最初は少額でも、PR案件やアフィリエイト報酬が積み上がると年間所得が大きくなることがあります。

早めに記録の習慣をつけておくと、確定申告の時期に慌てにくくなります。

## まとめ

Instagram副業で得た収入は、税金の対象になることがあります。

会社員の副業としてInstagramで収入を得ている場合、年間所得が20万円を超えると、所得税の確定申告が必要になる可能性があります。

判断するのは売上ではなく所得です。

```text
売上 − 経費 = 所得
```

PR案件、アフィリエイト、SNS運用代行、自分の商品販売などは、収入として記録しておきましょう。

また、商品提供やギフト券、ポイントなど、現金以外で受け取ったものも、案件の条件によっては注意が必要です。

まずは、収入、経費、商品提供、投稿URL、入金履歴を月ごとに整理するところから始めましょう。
