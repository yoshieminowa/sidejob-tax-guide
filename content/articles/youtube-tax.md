# YouTube収益の税金はいくらから？広告収入・案件・スパチャの確定申告を解説

YouTubeで収益が出始めると、気になるのが税金です。

広告収入、企業案件、スパチャ、メンバーシップ、アフィリエイトなど、YouTubeまわりの収入にはいくつか種類があります。

最初は趣味の延長でも、利益が出ていれば税金の対象になることがあります。

この記事では、YouTube収益がある人向けに、確定申告が必要になる目安、経費にできるもの、住民税の注意点、YouTube向けAdSenseの税務情報について、初心者向けにまとめます。

## YouTube収益は税金の対象になる？

YouTubeで得た収益は、基本的に税金の対象になります。

たとえば、次のような収入です。

* YouTube広告収入
* YouTubeショートの収益
* チャンネルメンバーシップ
* Super Chat、Super Stickers、Super Thanks
* 企業案件・PR案件の報酬
* アフィリエイト報酬
* 商品紹介による紹介料
* 自分の商品やサービス販売による売上
* 動画編集やチャンネル運用代行の報酬
* グッズ販売やデジタル商品の売上

YouTubeから直接入金される広告収入だけでなく、YouTubeをきっかけに発生した収入も、副業収入として考える必要があります。

## 収入と所得の違い

税金では、YouTube収益の「入金額」や「売上」がそのまま税金の対象になるわけではありません。

基本的には、次のように考えます。

```text
収入 - 経費 = 所得
```

たとえば、YouTube関連の年間収入が40万円あり、撮影機材、編集ソフト、通信費などに12万円かかった場合、所得は28万円です。

```text
収入40万円 - 経費12万円 = 所得28万円
```

確定申告が必要かどうかを考えるときは、収入ではなく所得を確認します。

## 会社員はYouTube所得が20万円を超えると確定申告が必要？

会社員やパートなどで給与をもらっている人は、YouTube収益などの副業所得が年間20万円を超えると、所得税の確定申告が必要になる可能性があります。

ここでいう20万円は、収入ではなく所得です。

| YouTube関連の年間収入 | 経費 | 所得 | 確定申告の目安 |
| ---: | ---: | ---: | --- |
| 5万円 | 2万円 | 3万円 | 所得税の確定申告は不要な可能性あり |
| 25万円 | 8万円 | 17万円 | 所得税の確定申告は不要な可能性あり |
| 50万円 | 15万円 | 35万円 | 確定申告が必要になる可能性あり |

ただし、医療費控除、ふるさと納税、住宅ローン控除の初年度などで確定申告をする場合は、YouTube所得も一緒に申告する必要があります。

また、所得税の確定申告が不要でも、住民税の申告が必要になる場合があります。

## YouTube収益は雑所得？事業所得？

YouTube収益の所得区分は、主に次のどちらかになることが多いです。

| 所得区分 | 目安 |
| --- | --- |
| 雑所得 | 趣味や副業として小規模に収入を得ている |
| 事業所得 | 継続的に収益化し、事業として運営している |

会社員が本業の合間に動画投稿をして、少し広告収入や案件収入がある程度なら、雑所得として考えるケースが多いです。

一方で、継続的に動画投稿を行い、毎月収入があり、帳簿をつけて事業として運営している場合は、事業所得になる可能性もあります。

どちらになるかは、収入の規模、継続性、事業としての実態、帳簿の有無などで判断されます。

迷う場合は、税務署や税理士に確認した方が安心です。

## YouTube収益の主な種類

YouTubeまわりの収入は、広告収入だけではありません。

| 収入の種類 | 内容 |
| --- | --- |
| 広告収入 | 動画やショートなどから発生する収益 |
| メンバーシップ | 視聴者が月額で加入する収益 |
| Super Chat | ライブ配信中の投げ銭 |
| Super Stickers | ライブ配信中のスタンプ購入 |
| Super Thanks | 動画に対する投げ銭のような機能 |
| 企業案件 | 商品やサービスを紹介して報酬を受け取る |
| アフィリエイト | 紹介リンク経由で購入や登録があると報酬が入る |
| 商品販売 | グッズ、PDF、講座、オンライン相談などの販売 |
| 外部収入 | note、ブログ、LINE、メルマガなどへの誘導による収益 |

どの収入も、利益が出ていれば税金の対象になる可能性があります。

## YouTube広告収入の税金

YouTubeの広告収入やショート動画などの収益は、YouTube向けAdSenseを通じて支払われます。

YouTubeの収益は、1か月を通じて累積され、月末後に調整される場合があります。

たとえば、次のような要因で最終的な収益額が変わることがあります。

* 無効なトラフィック
* Content IDの申し立て
* 特定の広告キャンペーン
* 米国視聴者から得た収益に対する税金
* 為替や支払い処理のタイミング

確定申告では、YouTube Studioの推定収益だけでなく、実際に確定した収益や入金額も確認しましょう。

## YouTube向けAdSenseの税務情報に注意

YouTubeで収益化しているクリエイターは、YouTube向けAdSenseで税務情報を確認・更新する必要があります。

これは、日本に住んでいるクリエイターも対象です。

税務情報を提出していない場合、源泉徴収が発生する可能性があります。

また、税務フォームは一度出せば永久に有効というわけではなく、期限切れになることがあります。

YouTube収益がある人は、YouTube向けAdSenseの税務情報が最新かどうかを定期的に確認しましょう。

## スパチャ・メンバーシップも税金の対象？

Super Chat、Super Stickers、Super Thanks、チャンネルメンバーシップなどの収益も、税金の対象になります。

視聴者からの応援に近い感覚でも、換金されて収益として受け取る場合は、収入として記録しておきましょう。

たとえば、次のような収入です。

* ライブ配信中のSuper Chat
* Super Stickers
* Super Thanks
* チャンネルメンバーシップの月額収益
* メンバー限定動画や特典による収益

投げ銭系の収入は、1回ごとは少額でも、配信回数が多いと年間で大きくなることがあります。

月ごとに収益額を確認しておくと整理しやすいです。

## 企業案件・PR案件の報酬は税金の対象？

YouTubeで企業案件やPR案件を受けた場合、その報酬は税金の対象になります。

たとえば、次のようなケースです。

* 商品紹介動画1本で報酬を受け取った
* サービス紹介動画を投稿して報酬を受け取った
* 動画概要欄への掲載で報酬を受け取った
* 成果報酬型のPR案件で報酬が入った
* ライブ配信で商品を紹介して報酬を受け取った

銀行振込だけでなく、ポイント、ギフト券、電子マネーなどで受け取った場合も、実質的な報酬であれば記録しておきましょう。

## アフィリエイト報酬も税金の対象？

動画概要欄や固定コメント、ブログ誘導などでアフィリエイト報酬が発生した場合も、税金の対象になります。

たとえば、次のような収入です。

* Amazonアソシエイトの報酬
* 楽天アフィリエイトの報酬
* ASP経由の成果報酬
* 美容、ガジェット、転職、金融、通信サービスなどの紹介報酬
* YouTubeからブログへ誘導して発生した広告収入

YouTube本体の収益だけでなく、YouTubeを入口にして発生した収入も記録しておきましょう。

## 商品提供を受けた場合は税金がかかる？

YouTubeでは、企業から商品提供を受けて動画で紹介することがあります。

商品提供は、現金を受け取っていなくても、案件の条件や商品の内容によっては経済的な利益として考える必要が出てくる場合があります。

特に、次のようなケースは注意が必要です。

* 動画投稿を条件に商品を受け取った
* 高額な商品を提供された
* 商品提供に加えて報酬も受け取った
* 継続的に商品提供を受けている
* 受け取った商品を後で販売している

商品提供を受けた場合は、少なくとも次の内容をメモしておくと安心です。

* 提供元の企業名
* 商品名
* おおよその価格
* 受け取った日
* 投稿条件の有無
* 報酬の有無
* 投稿URL

現金ではないから記録しなくてよい、と考えない方が安全です。

## YouTube収益で経費にできるもの

YouTube収益を得るために必要だった支出は、経費にできる可能性があります。

代表的なものは次のとおりです。

| 経費の例 | 内容 |
| --- | --- |
| 撮影機材 | カメラ、三脚、ライト、マイクなど |
| 編集ソフト | Adobe Premiere Pro、Final Cut Pro、Canvaなど |
| 有料素材 | BGM、効果音、写真素材、フォントなど |
| 撮影小物 | 背景布、商品撮影用の小物、装飾品など |
| 通信費の一部 | 動画投稿、配信、連絡、管理に使ったインターネット代 |
| スマホ・パソコン代の一部 | 撮影、編集、管理に使っている場合 |
| 外注費 | 動画編集、サムネイル制作、台本制作など |
| 交通費 | 撮影や取材のための移動費 |
| 書籍・セミナー代 | 動画制作や発信の学習費 |
| 会計ソフト代 | 売上や経費を管理するための費用 |

大切なのは、「YouTube収益を得るために必要だった」と説明できることです。

私用でも使っているものは、全額ではなく、仕事に使った分だけを経費にする考え方になります。

## カメラ・パソコン・スマホは全額経費にできる？

YouTube用にカメラ、パソコン、スマホを購入した場合、経費にできる可能性があります。

ただし、私生活でも使っている場合は、全額を経費にするのではなく、YouTubeで使った分だけを按分する考え方になります。

たとえば、パソコン代が20万円で、YouTube編集に使う割合が50％なら、YouTube関連の経費として考える金額は10万円です。

```text
パソコン代20万円 x 50% = YouTube分10万円
```

また、高額な機材は、購入した年に全額を経費にできるとは限らず、減価償却が関係する場合があります。

金額が大きい機材を買った場合は、会計ソフトや税理士相談を使うと安心です。

## 美容・服・食事・旅行代は経費にできる？

YouTubeでは、美容、ファッション、グルメ、旅行などのジャンルで発信している人もいます。

この場合、服、コスメ、食事代、旅行代などを経費にできるかが気になるところです。

結論としては、動画や案件のために直接必要だったものなら、経費にできる可能性があります。

ただし、私生活でも使えるものは、経費として説明しにくい場合があります。

| 支出 | 経費になりやすさ |
| --- | --- |
| 動画撮影専用の背景布やライト | 比較的説明しやすい |
| 商品レビュー用に購入した商品 | 投稿内容と記録があれば説明しやすい |
| 撮影企画のための入場料・交通費 | 企画内容と記録があれば説明しやすい |
| 普段も着る服 | 私用との区別が難しい |
| 日常的に使うコスメ | 私用との区別が難しい |
| 普段の外食 | 経費として説明しにくい |
| 私的な旅行 | 経費として説明しにくい |

投稿URL、企画内容、購入日、レシートをセットで残しておくと整理しやすくなります。

## YouTube収益の所得計算例

会社員が副業でYouTube収益を得ている例です。

| 項目 | 金額 |
| --- | ---: |
| YouTube広告収入 | 180,000円 |
| 企業案件の報酬 | 150,000円 |
| アフィリエイト報酬 | 70,000円 |
| 合計収入 | 400,000円 |
| 撮影機材 | 50,000円 |
| 編集ソフト | 24,000円 |
| 通信費の一部 | 36,000円 |
| 有料素材 | 10,000円 |
| 経費合計 | 120,000円 |
| 所得 | 280,000円 |

この場合、所得は次のように計算します。

```text
400,000円 - 120,000円 = 280,000円
```

会社員の副業としてこの所得が出ている場合、確定申告が必要になる可能性があります。

## 源泉徴収されている場合はどうする？

企業案件では、報酬から源泉徴収されて入金されることがあります。

たとえば、報酬額が5万円でも、実際の入金額がそれより少ないケースです。

この場合、入金額だけでなく、源泉徴収前の報酬額も確認しておきましょう。

確定申告では、源泉徴収された税額を反映することで、払いすぎた税金が戻る場合もあります。

企業から支払調書が届くこともありますが、届かない場合でも、自分で報酬額と源泉徴収額を記録しておくことが大切です。

## YouTube収益で住民税に注意

会社員の場合、副業所得が20万円以下なら、所得税の確定申告が不要になるケースがあります。

ただし、住民税は別です。

YouTube収益で所得が出ている場合、住民税の申告が必要になることがあります。

また、会社に副業を知られたくない人は、住民税の納付方法にも注意が必要です。

住民税の扱いは自治体によって異なるため、不安な場合は、住んでいる市区町村の窓口や公式サイトで確認しましょう。

## YouTube収益で開業届は必要？

YouTubeを始めたからといって、必ずすぐに開業届が必要になるわけではありません。

趣味や副業として小さく始めた段階では、まず収入と経費の記録を整えることが優先です。

一方で、次のような場合は開業届を検討してもよいでしょう。

* 継続的に収益が出ている
* 毎月安定した収入がある
* 企業案件を継続して受けている
* 請求書を発行している
* YouTubeを事業として育てたい
* 青色申告を使いたい

青色申告を使うには、原則として事前の届出が必要です。

節税面でメリットがある一方、帳簿づけの手間も増えるため、収入規模に合わせて考えましょう。

## YouTube収益でインボイス登録は必要？

YouTube収益がある個人が、必ずインボイス登録しなければならないわけではありません。

広告収入や個人向けの発信が中心なら、インボイス登録が不要なケースもあります。

一方で、企業からPR案件、動画制作、SNS運用代行を受けている場合、取引先からインボイス対応を求められる可能性があります。

ただし、インボイス登録をすると、消費税の申告が関係することがあります。

副業規模が小さいうちは、勢いで登録せず、取引先の要望、売上規模、今後の方針を確認してから判断しましょう。

## YouTube収益で残しておきたい記録

YouTube収益がある人は、次の記録を残しておくと確定申告のときに楽になります。

| 残すもの | 理由 |

| YouTube Studioの収益データ | 広告収入やメンバーシップ収益を確認するため |
| YouTube向けAdSenseの支払い明細 | 実際の支払い額を確認するため |
| 銀行口座の入金履歴 | 入金日と金額を確認するため |
| 企業案件の契約書・依頼文 | 報酬や投稿条件を確認するため |
| 請求書 | 案件報酬を整理するため |
| 源泉徴収額の記録 | 確定申告で必要になる場合があるため |
| アフィリエイト報酬明細 | 成果報酬を確認するため |
| 商品提供の記録 | 現金以外の利益を整理するため |
| 領収書・レシート | 経費の証拠になるため |
| 投稿URLや案件内容 | 何のための支出か説明しやすくするため |

特に、企業案件、商品提供、外部アフィリエイトは、YouTube Studioだけでは管理できません。

収入源ごとに分けて記録しておくと整理しやすくなります。

## YouTube収益の税金でよくある勘違い

### 登録者が少なければ税金は関係ない？

税金は登録者数ではなく、収入や所得で考えます。

登録者が少なくても、企業案件やアフィリエイト報酬で利益が出ていれば、税金の対象になる可能性があります。

### 収益化していなければ申告不要？

YouTubeの広告収益化をしていなくても、企業案件、アフィリエイト、商品販売などで収入があれば、税金の対象になることがあります。

YouTubeから直接入金があるかどうかだけで判断しないようにしましょう。

### スパチャは応援だから税金は関係ない？

Super Chatなどの投げ銭系収益も、換金されて収入として受け取る場合は、税金の対象になる可能性があります。

月ごとに記録しておきましょう。

### 売上が20万円以下なら何もしなくていい？

20万円で見るのは、売上や収入ではなく所得です。

また、所得税の確定申告が不要でも、住民税の申告が必要になる場合があります。

### カメラやパソコンは全部経費にできる？

YouTube専用なら経費として説明しやすいですが、私用でも使う場合は按分が必要です。

高額な機材は減価償却が関係することもあります。

## YouTube収益が出たらやること

YouTube収益が出始めたら、次の流れで整理するとわかりやすいです。

1. YouTube広告収入、案件、アフィリエイトなど収入の種類を分ける
2. 月ごとの収入を記録する
3. YouTube向けAdSenseの支払い明細を保存する
4. 撮影機材、編集ソフト、通信費などの経費を記録する
5. 商品提供を受けた場合は内容をメモする
6. 年間の所得を計算する
7. 所得が20万円を超えるか確認する
8. 住民税の申告が必要か確認する
9. 収入が増えてきたら会計ソフトや税理士相談を検討する

YouTube収益は、広告収入だけなら管理しやすいですが、案件やアフィリエイトが増えると複雑になります。

早めに収入源ごとに分けて記録しておくと、確定申告の時期に慌てにくくなります。

## まとめ

YouTube収益は、利益が出ていれば税金の対象になることがあります。

会社員の副業としてYouTube収益を得ている場合、年間所得が20万円を超えると、所得税の確定申告が必要になる可能性があります。

判断するのは収入ではなく所得です。

```text
収入 - 経費 = 所得
```

広告収入、メンバーシップ、スパチャ、企業案件、アフィリエイト、商品販売などは、収入として記録しておきましょう。

また、YouTube向けAdSenseの税務情報は、日本のクリエイターも確認・更新が必要です。

まずは、YouTube Studio、YouTube向けAdSense、銀行入金、案件報酬、経費の領収書を月ごとに整理するところから始めましょう。
