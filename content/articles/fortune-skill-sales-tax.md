# 占い・スキル販売の税金はいくらから？ココナラ・電話相談・鑑定料の確定申告を解説

占い、電話相談、チャット相談、カウンセリング、添削、アドバイス販売など、スキルを使った副業を始める人が増えています。

ココナラ、タイムチケット、SNS、LINE、Zoomなどを使って報酬を受け取る場合、利益が出ていれば税金の対象になることがあります。

この記事では、占い・スキル販売で収入が出た人向けに、確定申告が必要になる目安、経費にできるもの、住民税、開業届、インボイスの考え方を初心者向けにまとめます。

## 占い・スキル販売の収入は税金の対象になる？

占い・スキル販売で得た収入は、基本的に税金の対象になります。

たとえば、次のような報酬です。

* タロット占いの鑑定料
* 占星術・四柱推命・手相などの鑑定料
* 電話占い・チャット占いの報酬
* ココナラでのスキル販売報酬
* LINEやZoomを使った相談料
* 恋愛相談・キャリア相談の報酬
* 文章添削・プロフィール添削の報酬
* 画像診断・パーソナルカラー診断の報酬
* ハンドメイドやイラストのオーダー相談料
* noteやPDFで販売する鑑定書・レポートの売上

会社員の副業として行っている場合でも、報酬を受け取って利益が出ていれば、副業収入として記録しておく必要があります。

## 収入と所得の違い

税金では、受け取った報酬がそのまま税金の対象になるわけではありません。

基本的には、次のように計算します。

```text
収入 - 経費 = 所得
```

たとえば、占い・スキル販売で年間30万円の収入があり、手数料、通信費、鑑定用の資料、ツール代などに8万円かかった場合、所得は22万円です。

```text
収入30万円 - 経費8万円 = 所得22万円
```

確定申告が必要かどうかを考えるときは、収入ではなく所得を確認します。

## 会社員は所得が20万円を超えると確定申告が必要？

会社員やパートなどで給与をもらっている人は、占い・スキル販売などの副業所得が年間20万円を超えると、所得税の確定申告が必要になる可能性があります。

ここでいう20万円は、売上や報酬額ではなく所得です。

| 年間収入 | 経費 | 所得 | 確定申告の目安 |
| ---: | ---: | ---: | --- |
| 5万円 | 1万円 | 4万円 | 所得税の確定申告は不要な可能性あり |
| 25万円 | 8万円 | 17万円 | 所得税の確定申告は不要な可能性あり |
| 40万円 | 12万円 | 28万円 | 確定申告が必要になる可能性あり |

ただし、医療費控除、ふるさと納税、住宅ローン控除の初年度などで確定申告をする場合は、占い・スキル販売の所得も一緒に申告する必要があります。

また、所得税の確定申告が不要でも、住民税の申告が必要になる場合があります。

## 占い・スキル販売は雑所得？事業所得？

占い・スキル販売の所得区分は、主に次のどちらかになることが多いです。

| 所得区分 | 目安 |
| --- | --- |
| 雑所得 | 会社員の副業として小規模に行っている |
| 事業所得 | 継続的に集客・販売し、事業として運営している |

たとえば、会社員が休日にココナラで月数件だけ鑑定をしている程度なら、雑所得として考えるケースが多いです。

一方で、毎月継続して売上があり、SNSやブログで集客し、請求書や帳簿を管理している場合は、事業所得になる可能性もあります。

どちらになるかは、収入の規模、継続性、事業としての実態、帳簿の有無などで判断されます。

迷う場合は、税務署や税理士に確認した方が安心です。

## 占い・スキル販売の主な収入パターン

占い・スキル販売には、いくつかの収入パターンがあります。

| 収入の種類 | 内容 |
| --- | --- |
| 単発鑑定 | 1件ごとに鑑定料を受け取る |
| 電話・チャット相談 | 時間単位で相談料を受け取る |
| 月額相談 | 継続サポートとして毎月報酬を受け取る |
| PDF鑑定書販売 | 鑑定書や診断レポートを販売する |
| 講座・レッスン | 占い講座、スキル講座、相談スキル講座など |
| ココナラ販売 | ココナラ上でスキルを出品して報酬を受け取る |
| SNS経由販売 | Instagram、X、TikTokなどから申し込みを受ける |
| note販売 | 有料記事や鑑定テンプレートを販売する |
| Zoom相談 | オンライン面談形式で報酬を受け取る |

収入源が複数ある場合は、どこからいくら入ったかを分けて記録しておきましょう。

## ココナラやスキルマーケット経由の報酬はどうする？

ココナラ、タイムチケット、ストアカなどのスキルマーケット経由で報酬を受け取った場合も、収入として記録する必要があります。

また、サービス手数料が差し引かれて入金されることがあります。

この場合は、売上、手数料、入金額を分けて確認しましょう。

| 項目 | 金額例 |
| --- | ---: |
| 鑑定料・販売価格 | 10,000円 |
| サービス手数料 | 2,200円 |
| 実際の入金額 | 7,800円 |

サービス手数料は、販売のためにかかった費用として経費にできる可能性があります。

入金額だけを見ると収入を少なく見積もってしまうことがあるため、管理画面の売上明細を保存しておきましょう。

## SNSやLINEで直接受け取った報酬は？

Instagram、X、LINE、メール、Zoomなどを使って直接申し込みを受ける場合もあります。

銀行振込、PayPay、Stripe、Square、BASE、STORESなどで支払いを受けた場合も、収入として記録しましょう。

残しておきたい記録は次のとおりです。

* 申し込み日
* サービス内容
* 鑑定・相談日
* 料金
* 入金日
* 入金方法
* 相手の名前または管理用の識別情報
* 返金やキャンセルの有無

個人間のやり取りでは、後から記録を確認しにくくなります。

報酬を受け取った時点で、すぐにメモしておくと安心です。

## 占い・スキル販売で経費にできるもの

占い・スキル販売では、収入を得るために必要だった支出は経費にできる可能性があります。

代表的なものは次のとおりです。

| 経費の例 | 内容 |
| --- | --- |
| サービス手数料 | ココナラ、タイムチケットなどの販売手数料 |
| 通信費の一部 | Zoom、LINE、メール、SNS運用に使うインターネット代 |
| スマホ代の一部 | 相談、予約管理、顧客連絡に使う場合 |
| パソコン・タブレット代の一部 | 鑑定書作成、顧客管理、オンライン相談に使う場合 |
| 占い道具 | タロットカード、オラクルカード、鑑定用の道具など |
| 書籍・教材代 | 占い、心理学、相談技術、マーケティング学習のため |
| 有料ツール代 | 予約管理、決済、メルマガ、デザインツールなど |
| Canvaなどのデザインツール | 鑑定書、告知画像、PDF作成に使う場合 |
| SNS広告費 | 集客のための広告費 |
| ホームページ・ブログ費用 | サーバー代、ドメイン代、テーマ代など |
| 会計ソフト代 | 売上や経費を管理するための費用 |
| 外注費 | ロゴ、告知画像、LP、文章作成などを外注した場合 |

大切なのは、「占い・スキル販売の収入を得るために必要だった」と説明できることです。

私用でも使っているものは、全額ではなく、仕事に使った分だけを経費にする考え方になります。

## 占い道具やカードは経費にできる？

タロットカード、オラクルカード、ルーン、鑑定用の本などは、占いサービスに使っている場合、経費にできる可能性があります。

たとえば、次のようなものです。

* タロットカード
* オラクルカード
* ルーンストーン
* 占星術の専門書
* 鑑定用ソフト
* 鑑定書作成用テンプレート
* 相談記録用ノート
* オンライン鑑定用のマイクやライト

ただし、趣味でも使っている場合は、仕事で使っている割合に応じて按分する考え方になります。

たとえば、カード代が1万円で、仕事用として7割、私用として3割使っているなら、経費にする金額は7,000円です。

```text
10,000円 x 70% = 7,000円
```

割合は適当に決めるのではなく、自分で説明できる基準にしておきましょう。

## 書籍・講座代は経費にできる？

占い・スキル販売のために学んだ書籍や講座代は、経費にできる可能性があります。

たとえば、次のようなものです。

* 占星術やタロットの専門書
* 相談技術の本
* 心理学やコーチングの本
* 鑑定スキルの講座
* SNS集客の講座
* ライティングや販売ページ作成の教材
* Canvaやデザインの講座
* 確定申告や会計の本

ただし、単なる趣味や自己啓発としての支出は、経費として説明しにくい場合があります。

「どのサービスの売上につながる学習か」を説明できるようにしておくと整理しやすいです。

## 占い・スキル販売の所得計算例

会社員が副業で占い・相談サービスを販売している例です。

| 項目 | 金額 |
| --- | ---: |
| ココナラ鑑定料 | 180,000円 |
| LINE相談 | 120,000円 |
| PDF鑑定書販売 | 80,000円 |
| 合計収入 | 380,000円 |
| サービス手数料 | 50,000円 |
| 占い道具・書籍 | 30,000円 |
| 通信費の一部 | 24,000円 |
| Canva Pro | 18,000円 |
| SNS広告費 | 20,000円 |
| 経費合計 | 142,000円 |
| 所得 | 238,000円 |

この場合、所得は次のように計算します。

```text
380,000円 - 142,000円 = 238,000円
```

会社員の副業としてこの所得が出ている場合、確定申告が必要になる可能性があります。

## 返金やキャンセルがあった場合

占い・スキル販売では、返金やキャンセルが発生することもあります。

返金があった場合は、売上だけでなく返金額も記録しておきましょう。

| 項目 | 記録する内容 |
| --- | --- |
| キャンセル日 | いつキャンセルになったか |
| 返金額 | いくら返金したか |
| 返金方法 | 銀行振込、決済サービスなど |
| 手数料 | 返金時に手数料がかかったか |
| 理由 | トラブル防止のためにメモ |

売上管理画面や決済サービスの明細だけでは、後から理由がわかりにくい場合があります。

返金対応をしたら、簡単にメモを残しておきましょう。

## 住民税にも注意

会社員の場合、副業所得が20万円以下なら、所得税の確定申告が不要になるケースがあります。

ただし、住民税は別です。

占い・スキル販売で所得が出ている場合、住民税の申告が必要になることがあります。

また、会社に副業を知られたくない人は、住民税の納付方法にも注意が必要です。

住民税の扱いは自治体によって異なるため、不安な場合は住んでいる市区町村の窓口や公式サイトで確認しましょう。

## 開業届は必要？

占い・スキル販売を始めたからといって、必ずすぐに開業届が必要になるわけではありません。

趣味や副業として小さく始めた段階では、まず収入と経費の記録を整えることが優先です。

一方で、次のような場合は開業届を検討してもよいでしょう。

* 継続的に申し込みがある
* 毎月安定した売上がある
* SNSやブログで集客している
* 複数の販売サービスを使っている
* 請求書や領収書を発行している
* 事業として育てたい
* 青色申告を使いたい

青色申告を使うには、原則として事前の届出が必要です。

節税面でメリットがある一方、帳簿づけの手間も増えるため、収入規模に合わせて考えましょう。

## インボイス登録は必要？

占い・スキル販売をしている個人が、必ずインボイス登録しなければならないわけではありません。

個人のお客さん向けに鑑定や相談を提供している場合は、インボイス登録が不要なケースもあります。

一方で、法人向けに研修、講座、相談、鑑定コンテンツ制作などを提供している場合は、取引先からインボイス対応を求められる可能性があります。

ただし、インボイス登録をすると、消費税の申告が関係してくることがあります。

副業規模が小さいうちは、勢いで登録せず、取引先の要望、売上規模、今後の方針を確認してから判断しましょう。

## 占い・スキル販売で残しておきたい記録

占い・スキル販売をしている人は、次の記録を残しておくと確定申告のときに楽になります。

| 残すもの | 理由 |
| --- | --- |
| 売上明細 | ココナラなどの販売額を確認するため |
| 銀行口座の入金履歴 | 実際の入金額を確認するため |
| サービス手数料の記録 | 経費として整理するため |
| 決済サービスの明細 | Stripe、PayPay、Squareなどの入金確認 |
| 申込フォームの記録 | 申し込み内容を確認するため |
| 鑑定・相談日 | サービス提供日を確認するため |
| 返金・キャンセル記録 | 売上調整を確認するため |
| 領収書・レシート | 経費の証拠になるため |
| 書籍・講座の明細 | 学習費用を確認するため |
| SNS広告費の明細 | 集客費用を確認するため |
| 外注費の請求書 | ロゴやLP制作などの外注費確認 |

占い・スキル販売は、少額の取引が積み上がりやすい副業です。

月ごとに収入と経費を整理しておくと、確定申告の時期に慌てにくくなります。

## 占い・スキル販売の税金でよくある勘違い

### 趣味の占いだから税金は関係ない？

趣味に近い活動でも、報酬を受け取って利益が出ていれば、税金の対象になることがあります。

継続して販売している場合は、収入と経費を記録しておきましょう。

### ココナラ経由なら申告しなくていい？

ココナラなどのサービスを経由していても、報酬は収入として記録する必要があります。

サービス手数料も確認し、経費として整理しましょう。

### 銀行振込ではなくPayPayなら記録不要？

PayPay、電子マネー、ポイント、ギフト券などで受け取っても、実質的に報酬であれば記録が必要です。

現金かどうかだけで判断しないようにしましょう。

### 売上が20万円以下なら何もしなくていい？

20万円で見るのは、売上ではなく所得です。

また、所得税の確定申告が不要でも、住民税の申告が必要になる場合があります。

### 占い道具や本は全部経費にできる？

業務専用なら経費として説明しやすいですが、趣味でも使っている場合は按分が必要です。

仕事で使った割合を説明できるようにしておきましょう。

## 占い・スキル販売を始めたらやること

占い・スキル販売で報酬が出始めたら、次の流れで整理するとわかりやすいです。

1. 販売サービスごとに売上を記録する
2. 鑑定料、相談料、PDF販売など収入の種類を分ける
3. サービス手数料を確認する
4. 占い道具、書籍、通信費などの経費を記録する
5. 返金やキャンセルがあればメモする
6. 年間の所得を計算する
7. 所得が20万円を超えるか確認する
8. 住民税の申告が必要か確認する
9. 売上が増えてきたら会計ソフトや税理士相談を検討する

占い・スキル販売は、最初は小さな収入でも、件数が増えると年間所得が大きくなることがあります。

早めに記録の習慣を作っておくと、確定申告の時期に慌てにくくなります。

## まとめ

占い・スキル販売で得た報酬は、税金の対象になることがあります。

会社員の副業として占いや相談サービスを販売している場合、年間所得が20万円を超えると、所得税の確定申告が必要になる可能性があります。

判断するのは収入ではなく所得です。

```text
収入 - 経費 = 所得
```

ココナラの手数料、占い道具、書籍、通信費、Canva、SNS広告費などは、業務に必要だったと説明できれば経費にできる可能性があります。

まずは、売上明細、入金履歴、サービス手数料、経費の領収書を月ごとに整理しましょう。
