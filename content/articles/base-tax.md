# BASE販売の税金はいくらから？ネットショップ副業の確定申告をやさしく解説

BASEでネットショップを開き、ハンドメイド作品やオリジナルグッズ、仕入れ商品などを販売していると、気になるのが税金です。

「まだ小さなショップだから大丈夫」
「売上が少ないから申告しなくていい」
「趣味の延長だから税金は関係ない」

と思っていても、利益が出ている場合は税金の対象になることがあります。

この記事では、BASE販売をしている人向けに、確定申告が必要になる目安、経費にできるもの、住民税の注意点をわかりやすくまとめます。

## BASE販売の収入は税金の対象になる？

BASEで商品を販売して得た収入は、基本的に税金の対象になります。

たとえば、次のような販売です。

* ハンドメイド作品の販売
* アクセサリーや雑貨の販売
* アパレル商品の販売
* 仕入れ商品の販売
* オリジナルグッズの販売
* デジタル商品の販売
* 食品やコスメなどの販売

ただし、税金の判断では「売上」ではなく「所得」を見ます。

## 売上と所得の違い

BASE販売では、売上がそのまま税金の対象になるわけではありません。

税金では、基本的に次のように考えます。

```text
売上 − 経費 = 所得
```

たとえば、BASEで年間50万円売れたとしても、仕入れ代、材料費、送料、梱包資材、BASEの手数料などに35万円かかっていれば、所得は15万円です。

```text
売上50万円 − 経費35万円 = 所得15万円
```

確定申告が必要かどうかを考えるときは、売上ではなく、この「所得」を確認します。

## 会社員はBASEの所得が20万円を超えると確定申告が必要？

会社員やパートなどで給与をもらっている人は、BASE販売などの副業所得が年間20万円を超えると、所得税の確定申告が必要になる可能性があります。

ここでいう20万円は、売上ではなく所得です。

| BASEの年間売上 | 経費 | 所得 | 確定申告の目安 |
| ---: | ---: | ---: | --- |
| 10万円 | 7万円 | 3万円 | 所得税の確定申告は不要な可能性あり |
| 40万円 | 25万円 | 15万円 | 所得税の確定申告は不要な可能性あり |
| 70万円 | 40万円 | 30万円 | 確定申告が必要になる可能性あり |

ただし、医療費控除、ふるさと納税、住宅ローン控除の初年度などで確定申告をする場合は、BASE販売の所得も一緒に申告する必要があります。

また、所得税の確定申告が不要でも、住民税の申告が必要になる場合があります。

## BASE販売は雑所得？事業所得？

BASE販売の所得区分は、主に次のどちらかになることが多いです。

| 所得区分 | 目安 |
| --- | --- |
| 雑所得 | 趣味・副業として小規模に販売している |
| 事業所得 | 継続的に販売し、事業として運営している |

たとえば、会社員が休日にハンドメイド作品を販売している程度なら、雑所得として考えるケースが多いです。

一方で、ショップを継続的に運営し、売上規模が大きく、仕入れ・在庫管理・帳簿管理を行っている場合は、事業所得になる可能性もあります。

どちらになるかは、販売頻度、売上規模、継続性、帳簿の有無などで判断されます。

迷う場合は、税務署や税理士に確認した方が安心です。

## BASE販売で経費にできるもの

BASE販売では、商品を売るために必要だった支出は経費にできる可能性があります。

代表的なものは次のとおりです。

| 経費の例 | 内容 |
| --- | --- |
| 仕入れ代 | 販売する商品の仕入れ費用 |
| 材料費 | ハンドメイド作品の材料、パーツ、布、金具など |
| 制作費 | 外注費、印刷代、グッズ制作費など |
| 梱包資材 | 封筒、段ボール、緩衝材、OPP袋など |
| 送料 | 商品発送にかかった費用 |
| BASEの決済手数料 | 商品が売れたときにかかる手数料 |
| BASEのサービス利用料 | 販売時にかかる利用料 |
| 撮影用品 | 商品写真用の背景紙、ライト、小物など |
| 広告宣伝費 | SNS広告、チラシ、ショップカードなど |
| 通信費の一部 | ショップ運営に使ったインターネット代など |
| パソコン・スマホ代の一部 | 販売管理や商品撮影に使っている場合 |
| 会計ソフト代 | 売上や経費を管理するための費用 |

大切なのは、「BASE販売のために使った」と説明できることです。

私用でも使っているものは、全額ではなく、仕事に使った分だけを経費にする考え方になります。

## BASEの手数料は経費にできる？

BASEでは、商品が売れたときに決済手数料やサービス利用料がかかります。

これらは販売のために必要な費用なので、経費にできる可能性があります。

BASEのスタンダードプランでは、商品が売れたときに決済手数料とサービス利用料がかかります。

また、グロースプランでは月額費用がかかる代わりに、販売時の手数料が抑えられる仕組みです。

手数料はプランや決済方法によって変わるため、確定申告のときはBASEの管理画面や売上明細で確認しましょう。

## BASE販売の所得計算例

BASEでハンドメイドアクセサリーを販売している場合を例にします。

| 項目 | 金額 |
| --- | ---: |
| 年間売上 | 600,000円 |
| 材料費 | 180,000円 |
| 梱包資材 | 30,000円 |
| 送料 | 60,000円 |
| BASE手数料 | 45,000円 |
| 撮影用品・備品 | 20,000円 |
| 所得 | 265,000円 |

この場合、所得は次のように計算します。

```text
600,000円 − 335,000円 = 265,000円
```

会社員の副業としてこの所得が出ている場合、確定申告が必要になる可能性があります。

## 在庫がある場合は注意

BASE販売では、仕入れた商品や材料がすべてその年の経費になるとは限りません。

たとえば、商品を仕入れても、年末時点でまだ売れていない在庫が残っている場合、その分は在庫として整理する必要があります。

ざっくり言うと、売れた商品に対応する仕入れや材料費が経費になります。

次のようなものは、年末時点で残っていないか確認しておきましょう。

* 未販売の商品
* 未使用の材料
* 制作済みだが売れていない作品
* 仕入れたまま保管している商品

小規模な副業でも、在庫が多い場合は計算がやや複雑になります。

売上が増えてきたら、会計ソフトを使うか、税理士に相談すると安心です。

## BASE販売で住民税に注意

会社員の場合、副業所得が20万円以下なら、所得税の確定申告が不要になるケースがあります。

ただし、住民税は別です。

BASE販売で所得が出ている場合、住民税の申告が必要になることがあります。

また、会社に副業を知られたくない人は、住民税の納付方法にも注意が必要です。

住民税の扱いは自治体によって異なるため、不安な場合は、住んでいる市区町村の窓口や公式サイトで確認しましょう。

## BASE販売で開業届は必要？

BASE販売を始めたからといって、必ずすぐに開業届が必要になるわけではありません。

趣味や副業として小さく始めた段階では、まず売上と経費の記録を整えることが優先です。

一方で、次のような場合は開業届を検討してもよいでしょう。

* 継続的に販売している
* 毎月売上がある
* 仕入れや在庫管理をしている
* 事業として育てたい
* 青色申告を使いたい

青色申告を使うには、原則として事前の届出が必要です。

節税面でメリットがある一方、帳簿づけの手間も増えるため、売上規模に合わせて考えましょう。

## BASE販売でインボイス登録は必要？

BASEで販売している個人が、必ずインボイス登録しなければならないわけではありません。

個人のお客さん向けにアクセサリー、雑貨、アパレル、ハンドメイド作品などを販売している場合は、インボイス登録が不要なケースもあります。

一方で、法人や個人事業主向けに商品を販売している場合は、取引先からインボイス対応を求められる可能性があります。

ただし、インボイス登録をすると、消費税の申告が関係することがあります。

小規模な副業の場合は、勢いで登録せず、自分の販売先や売上規模を確認してから判断しましょう。

## BASE販売で残しておきたい記録

BASE販売をしている人は、次の記録を残しておくと確定申告のときに楽になります。

| 残すもの | 理由 |
| --- | --- |
| BASEの売上明細 | 年間売上を確認するため |
| 振込明細 | 実際の入金額を確認するため |
| 決済手数料・サービス利用料の記録 | 経費として整理するため |
| 仕入れ代の領収書 | 売上原価を確認するため |
| 材料費の領収書 | ハンドメイド作品の経費になるため |
| 送料の記録 | 発送費用を確認するため |
| 梱包資材のレシート | 経費の証拠になるため |
| 在庫の記録 | 年末時点の在庫確認に使うため |

最初から完璧な帳簿を作ろうとすると大変です。

まずは、月ごとに売上と経費を分けて保存するところから始めましょう。

## BASE販売の税金でよくある勘違い

### 売上が20万円以下なら何もしなくていい？

20万円で見るのは、売上ではなく所得です。

```text
売上 − 経費 = 所得
```

売上が30万円でも、経費が15万円なら所得は15万円です。

### BASEから振り込まれた金額だけ見ればいい？

振込額だけでは、売上、手数料、送料、経費の内訳がわかりにくいことがあります。

BASEの管理画面で、売上明細や手数料を確認しましょう。

### ハンドメイドだから税金は関係ない？

ハンドメイドでも、継続して販売して利益が出ていれば、税金の対象になることがあります。

趣味かどうかだけではなく、販売の継続性や利益の有無が大切です。

### 赤字なら何もしなくていい？

赤字でも、売上や経費の記録は残しておきましょう。

特に事業所得として申告する場合や、翌年以降も販売を続ける場合は、記録があると判断しやすくなります。

## BASE販売を始めたらやること

BASE販売を始めたら、次の流れで整理するとわかりやすいです。

1. BASEの売上明細を月ごとに確認する
2. 仕入れ代、材料費、送料、梱包資材を記録する
3. BASEの手数料を確認する
4. 年間の所得を計算する
5. 所得が20万円を超えるか確認する
6. 住民税の申告が必要か確認する
7. 売上が増えたら会計ソフトや税理士相談を検討する

BASE販売は、売上だけを見ると利益が出ているように見えても、仕入れや送料、手数料を引くと意外と所得が少ないこともあります。

毎月ざっくりでも記録しておくと、確定申告の時期に慌てにくくなります。

## まとめ

BASE販売で得た利益は、税金の対象になることがあります。

会社員の副業としてBASE販売をしている場合、年間所得が20万円を超えると、所得税の確定申告が必要になる可能性があります。

ただし、判断するのは売上ではなく所得です。

```text
売上 − 経費 = 所得
```

仕入れ代、材料費、送料、梱包資材、BASEの手数料などは、経費にできる可能性があります。

まずは、BASEの売上明細、手数料、領収書、在庫の記録を残しておきましょう。
