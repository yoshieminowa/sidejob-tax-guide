# デザイン副業の税金はいくらから？ロゴ・バナー・サムネイル制作の確定申告を解説

ロゴ制作、バナー制作、サムネイル作成、SNS投稿画像、チラシ、Canvaテンプレート制作など、デザイン副業を始める人が増えています。

最初は小さな案件でも、報酬を受け取って利益が出ていれば、税金の対象になることがあります。

この記事では、デザイン副業で収入が出た人向けに、確定申告が必要になる目安、経費にできるもの、源泉徴収、住民税、開業届の考え方を初心者向けにまとめます。

## デザイン副業の収入は税金の対象になる？

デザイン副業で得た収入は、基本的に税金の対象になります。

たとえば、次のような報酬です。

* ロゴ制作の報酬
* バナー制作の報酬
* YouTubeサムネイル制作の報酬
* Instagram投稿画像の制作報酬
* チラシ・ポスター制作の報酬
* 名刺デザインの報酬
* LP画像や広告画像の制作報酬
* Canvaテンプレート制作の報酬
* SNS運用代行の一部としての画像制作報酬
* ココナラやクラウドワークス経由のデザイン報酬

会社員の副業として行っている場合でも、継続的に報酬を受け取っていれば、副業収入として記録しておく必要があります。

## 収入と所得の違い

税金では、受け取った報酬がそのまま税金の対象になるわけではありません。

基本的には、次のように計算します。

```text
収入 - 経費 = 所得
```

たとえば、デザイン副業で年間35万円の報酬があり、Canva、Adobe、素材サイト、通信費などに10万円かかった場合、所得は25万円です。

```text
収入35万円 - 経費10万円 = 所得25万円
```

確定申告が必要かどうかを考えるときは、収入ではなく所得を確認します。

## 会社員はデザイン副業の所得が20万円を超えると確定申告が必要？

会社員やパートなどで給与をもらっている人は、デザイン副業などの所得が年間20万円を超えると、所得税の確定申告が必要になる可能性があります。

ここでいう20万円は、売上や報酬額ではなく所得です。

| デザイン副業の年間収入 | 経費 | 所得 | 確定申告の目安 |
| ---: | ---: | ---: | --- |
| 10万円 | 4万円 | 6万円 | 所得税の確定申告は不要な可能性あり |
| 30万円 | 12万円 | 18万円 | 所得税の確定申告は不要な可能性あり |
| 50万円 | 15万円 | 35万円 | 確定申告が必要になる可能性あり |

ただし、医療費控除、ふるさと納税、住宅ローン控除の初年度などで確定申告をする場合は、デザイン副業の所得も一緒に申告する必要があります。

また、所得税の確定申告が不要でも、住民税の申告が必要になる場合があります。

## デザイン副業は雑所得？事業所得？

デザイン副業の所得区分は、主に次のどちらかになることが多いです。

| 所得区分 | 目安 |
| --- | --- |
| 雑所得 | 会社員の副業として小規模に受けている |
| 事業所得 | 継続的に案件を受け、事業として運営している |

たとえば、会社員が空き時間に月1〜2件だけデザイン案件を受けている程度なら、雑所得として考えるケースが多いです。

一方で、複数のクライアントと契約し、毎月継続して報酬があり、請求書を発行して帳簿をつけている場合は、事業所得になる可能性もあります。

どちらになるかは、収入の規模、継続性、事業としての実態、帳簿の有無などで判断されます。

迷う場合は、税務署や税理士に確認した方が安心です。

## デザイン副業の主な収入パターン

デザイン副業には、いくつかの収入パターンがあります。

| 収入の種類 | 内容 |
| --- | --- |
| 単発制作 | ロゴ、バナー、サムネイルなどを1件ごとに制作 |
| 月額契約 | 毎月SNS画像や広告バナーを制作 |
| テンプレート制作 | Canvaテンプレートなどを制作 |
| SNS運用込み | 投稿画像、キャプション、分析まで担当 |
| クラウドソーシング案件 | ココナラ、クラウドワークス、ランサーズなどで受注 |
| 企業案件 | 企業や店舗から直接依頼を受ける |
| 印刷物デザイン | チラシ、名刺、パンフレットなどを制作 |
| 販売型 | BOOTH、BASE、noteなどでデザイン素材を販売 |

受託制作なのか、テンプレート販売なのかで、記録する内容や経費が少し変わります。

## 業務委託の報酬はどう記録する？

デザイン副業は、業務委託として受けることが多いです。

報酬を受け取ったら、次の内容を記録しておきましょう。

* クライアント名
* 案件内容
* 制作物の種類
* 請求日
* 入金日
* 請求額
* 源泉徴収の有無
* 振込手数料の負担
* 消費税の有無
* 使用したソフトや素材

月額契約の場合は、毎月の請求額と入金額を分けて管理するとわかりやすいです。

単発案件の場合も、案件ごとに記録しておくと後から確認しやすくなります。

## 源泉徴収されている場合はどうする？

デザイン料は、契約内容や支払者によって、源泉徴収されて入金されることがあります。

たとえば、請求額が5万円でも、実際の入金額がそれより少ないケースです。

| 項目 | 金額例 |
| --- | ---: |
| 請求額 | 50,000円 |
| 源泉徴収税額 | 5,105円 |
| 入金額 | 44,895円 |

この場合、入金額だけでなく、源泉徴収前の報酬額も確認しておきましょう。

確定申告では、源泉徴収された税額を反映することで、払いすぎた税金が戻る場合もあります。

支払調書が届くこともありますが、届かない場合でも、自分で請求額、入金額、源泉徴収額を記録しておくことが大切です。

## デザイン副業で経費にできるもの

デザイン副業では、収入を得るために必要だった支出は経費にできる可能性があります。

代表的なものは次のとおりです。

| 経費の例 | 内容 |
| --- | --- |
| デザインソフト代 | Adobe Photoshop、Illustrator、Canva Proなど |
| フォント代 | 商用利用可能なフォント、フォントサービスなど |
| 有料素材代 | 写真素材、イラスト素材、アイコン、テンプレートなど |
| パソコン代の一部 | デザイン作業に使うPC |
| タブレット代の一部 | iPad、ペンタブなど |
| ペン・周辺機器 | Apple Pencil、ペンタブ、マウスなど |
| モニター代の一部 | デザイン確認用モニター |
| 通信費の一部 | 納品、連絡、データ共有に使うインターネット代 |
| スマホ代の一部 | クライアント連絡や確認に使う場合 |
| 書籍・教材代 | デザイン、配色、マーケティング学習のため |
| セミナー・講座代 | デザインスキル習得のため |
| 印刷代 | 試し刷り、見本、納品用印刷物など |
| 会計ソフト代 | 売上や経費を管理するための費用 |
| 外注費 | イラスト、写真、ライティングなどを外注した場合 |

大切なのは、「デザイン副業の収入を得るために必要だった」と説明できることです。

私用でも使っているものは、全額ではなく、仕事に使った分だけを経費にする考え方になります。

## AdobeやCanvaなどのソフト代は経費にできる？

デザイン副業で使うAdobe Photoshop、Illustrator、Canva Proなどは、業務に使っている場合、経費にできる可能性があります。

たとえば、次のような支出です。

* Adobe Creative Cloud
* Photoshop
* Illustrator
* Canva Pro
* Figmaの有料プラン
* Affinity Designer
* Procreate
* フォントサービス
* 素材サイト
* テンプレート販売用の制作ツール

ただし、趣味や私用でも使っている場合は、仕事で使っている割合に応じて按分する考え方になります。

たとえば、Adobe代が月6,000円で、8割をデザイン副業、2割を私用で使っているなら、経費にする金額は月4,800円です。

```text
6,000円 x 80% = 4,800円
```

割合は適当に決めるのではなく、自分で説明できる基準にしておきましょう。

## パソコンやiPadは全額経費にできる？

デザイン用にパソコン、iPad、ペンタブ、モニターなどを購入した場合、経費にできる可能性があります。

ただし、私用でも使っている場合は、全額を経費にするのではなく、デザイン副業で使った分だけを按分します。

たとえば、20万円のパソコンを購入し、デザイン副業で使う割合が70%なら、デザイン副業分として考える金額は14万円です。

```text
20万円 x 70% = 14万円
```

また、高額なパソコンや機材は、購入した年に全額を経費にできるとは限らず、減価償却が関係する場合があります。

金額が大きい機材を買った場合は、会計ソフトや税理士相談を使うと安心です。

## フォントや素材のライセンスにも注意

デザイン副業では、フォントや素材のライセンスにも注意が必要です。

無料素材でも、商用利用できないものがあります。

クライアントワークで使う場合は、次の点を確認しましょう。

* 商用利用できるか
* クライアント案件で使えるか
* 加工できるか
* ロゴに使えるか
* 再配布やテンプレート販売に使えるか
* クレジット表記が必要か

税金とは別の話ですが、後からトラブルになりやすい部分です。

有料素材や有料フォントを購入した場合は、領収書だけでなく、利用規約やライセンス条件も保存しておくと安心です。

## クラウドソーシング経由の報酬はどうする？

デザイン副業は、ココナラ、クラウドワークス、ランサーズなどで受けることもあります。

クラウドソーシング経由でも、報酬は収入として記録する必要があります。

また、サービス手数料が差し引かれて入金される場合があります。

この場合は、売上、手数料、入金額を分けて確認しましょう。

| 項目 | 金額例 |
| --- | ---: |
| 案件報酬 | 30,000円 |
| サービス手数料 | 6,000円 |
| 実際の入金額 | 24,000円 |

サービス手数料は、販売や受注のためにかかった費用として経費にできる可能性があります。

入金額だけを見ると収入を少なく見積もってしまうことがあるため、管理画面の明細を保存しておきましょう。

## 外注費がある場合は注意

デザイン案件が増えてくると、作業の一部を外注することがあります。

たとえば、次のような外注です。

* イラスト制作を外注した
* 写真撮影を外注した
* ライティングを外注した
* コーディングを外注した
* 印刷作業を外注した
* デザインの一部を別の制作者に依頼した

外注費は、業務に必要な費用として経費にできる可能性があります。

ただし、誰に、何を、いくらで依頼したのかを記録しておきましょう。

請求書、領収書、支払い履歴、チャットでの依頼内容などを残しておくと安心です。

## デザイン副業の所得計算例

会社員が副業でデザイン制作をしている例です。

| 項目 | 金額 |
| --- | ---: |
| ロゴ制作 | 120,000円 |
| バナー制作 | 160,000円 |
| YouTubeサムネイル制作 | 100,000円 |
| 合計収入 | 380,000円 |
| Adobe代 | 72,000円 |
| Canva Pro | 18,000円 |
| 有料素材・フォント | 30,000円 |
| 通信費の一部 | 24,000円 |
| 書籍・教材 | 10,000円 |
| 経費合計 | 154,000円 |
| 所得 | 226,000円 |

この場合、所得は次のように計算します。

```text
380,000円 - 154,000円 = 226,000円
```

会社員の副業としてこの所得が出ている場合、確定申告が必要になる可能性があります。

## 住民税にも注意

会社員の場合、副業所得が20万円以下なら、所得税の確定申告が不要になるケースがあります。

ただし、住民税は別です。

デザイン副業で所得が出ている場合、住民税の申告が必要になることがあります。

また、会社に副業を知られたくない人は、住民税の納付方法にも注意が必要です。

住民税の扱いは自治体によって異なるため、不安な場合は住んでいる市区町村の窓口や公式サイトで確認しましょう。

## 開業届は必要？

デザイン副業を始めたからといって、必ずすぐに開業届が必要になるわけではありません。

趣味や副業として小さく始めた段階では、まず収入と経費の記録を整えることが優先です。

一方で、次のような場合は開業届を検討してもよいでしょう。

* 継続的に案件を受けている
* 複数のクライアントがいる
* 毎月安定した収入がある
* 請求書を発行している
* デザイン業を事業として育てたい
* 青色申告を使いたい

青色申告を使うには、原則として事前の届出が必要です。

節税面でメリットがある一方、帳簿づけの手間も増えるため、収入規模に合わせて考えましょう。

## インボイス登録は必要？

デザイン副業をしている個人が、必ずインボイス登録しなければならないわけではありません。

ただし、デザイン副業は法人や個人事業主のクライアントから仕事を受けることがあるため、取引先からインボイス対応を求められる可能性があります。

特に、次のような場合は確認が必要です。

* 法人クライアントが多い
* 継続契約をしている
* 請求書を毎月発行している
* 消費税額を記載した請求書を求められる
* 今後、事業として拡大したい

ただし、インボイス登録をすると、消費税の申告が関係してくることがあります。

副業規模が小さいうちは、勢いで登録せず、取引先の要望、売上規模、今後の方針を確認してから判断しましょう。

## デザイン副業で残しておきたい記録

デザイン副業をしている人は、次の記録を残しておくと確定申告のときに楽になります。

| 残すもの | 理由 |
| --- | --- |
| 契約書・業務委託契約書 | 業務内容や報酬を確認するため |
| 請求書 | 請求額を確認するため |
| 銀行口座の入金履歴 | 実際の入金額を確認するため |
| 源泉徴収額の記録 | 確定申告で必要になる場合があるため |
| クライアントとの依頼文 | 何の業務か確認するため |
| 領収書・レシート | 経費の証拠になるため |
| ソフトの利用明細 | AdobeやCanvaなどの経費確認に使うため |
| 素材・フォントの領収書 | 有料素材の経費確認に使うため |
| ライセンス条件 | 商用利用の確認に使うため |
| 外注費の請求書 | 外注費を整理するため |
| 納品物や作業内容の記録 | 収入との対応関係を説明しやすくするため |

デザイン副業は、案件ごとに内容が違いやすい副業です。

クライアント名、作業内容、請求額、入金日を一覧にしておくと管理しやすくなります。

## デザイン副業の税金でよくある勘違い

### 報酬が手渡しなら申告しなくていい？

手渡しでも銀行振込でも、収入があることに変わりはありません。

報酬を受け取ったら、日付、相手、金額、内容を記録しておきましょう。

### ココナラ経由なら記録しなくていい？

ココナラ、クラウドワークス、ランサーズなどを経由した場合でも、報酬は収入として記録する必要があります。

サービス手数料も確認し、経費として整理しましょう。

### 源泉徴収されていれば確定申告はいらない？

源泉徴収されていても、確定申告が必要になる場合があります。

また、確定申告をすることで、源泉徴収された税金の一部が戻ることもあります。

### 売上が20万円以下なら何もしなくていい？

20万円で見るのは、売上ではなく所得です。

また、所得税の確定申告が不要でも、住民税の申告が必要になる場合があります。

### AdobeやiPad代は全部経費にできる？

業務専用なら経費として説明しやすいですが、私用でも使っている場合は按分が必要です。

高額なパソコンやタブレットは、減価償却が関係する場合もあります。

## デザイン副業を始めたらやること

デザイン副業で報酬が出始めたら、次の流れで整理するとわかりやすいです。

1. クライアントごとに報酬を記録する
2. 請求書と入金日を管理する
3. 源泉徴収の有無を確認する
4. Adobe、Canva、素材サイト、通信費などの経費を記録する
5. 業務委託契約書や依頼文を保存する
6. 素材やフォントのライセンスを保存する
7. 年間の所得を計算する
8. 所得が20万円を超えるか確認する
9. 住民税の申告が必要か確認する
10. 案件が増えてきたら会計ソフトや税理士相談を検討する

デザイン副業は、ソフト代、素材代、フォント代などの経費が発生しやすい副業です。

早めに記録の習慣を作っておくと、確定申告の時期に慌てにくくなります。

## まとめ

デザイン副業で得た報酬は、税金の対象になることがあります。

会社員の副業としてデザイン制作をしている場合、年間所得が20万円を超えると、所得税の確定申告が必要になる可能性があります。

判断するのは収入ではなく所得です。

```text
収入 - 経費 = 所得
```

Adobe、Canva、Figma、素材サイト、フォント、通信費、パソコン、iPadなどは、業務に必要だったと説明できれば経費にできる可能性があります。

まずは、クライアントごとの報酬、請求書、入金履歴、源泉徴収額、経費の領収書を月ごとに整理しましょう。
