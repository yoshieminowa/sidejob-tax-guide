# BOOTH販売の税金はいくらから？同人誌・グッズ・ダウンロード販売の確定申告をやさしく解説

BOOTHで同人誌やグッズ、イラスト素材、ダウンロードデータなどを販売していると、気になるのが「税金はどうなるの？」という点です。

趣味で少し売っているだけでも、利益が出ていれば税金の対象になることがあります。

この記事では、BOOTH販売をしている人向けに、確定申告が必要になる目安、経費にできるもの、住民税の注意点を初心者向けにまとめます。

## BOOTH販売の収入は税金の対象になる？

BOOTHで販売して得た収入は、基本的に税金の対象になります。

たとえば、次のような販売です。

- 同人誌の販売
- アクリルキーホルダーやステッカーなどのグッズ販売
- ハンドメイド作品の販売
- イラスト素材やテンプレートの販売
- PDF、音声、画像データなどのダウンロード販売
- pixivFACTORYを使った受注販売

ただし、税金がかかるかどうかは「売上」ではなく「所得」で考えます。

## 売上と所得の違い

BOOTHで考えると、売上と所得は次のように違います。

```text
売上 − 経費 = 所得
```

たとえば、BOOTHで年間10万円売れたとしても、印刷代や材料費、送料、梱包資材などに7万円かかっていれば、所得は3万円です。

```text
売上10万円 − 経費7万円 = 所得3万円
```

税金の判断では、基本的にこの「所得」が重要になります。

## 会社員はBOOTHの所得が20万円を超えると確定申告が必要？

会社員やパートなどで給与をもらっている人は、BOOTH販売などの副業所得が年間20万円を超えると、所得税の確定申告が必要になる可能性があります。

ここでいう20万円は、売上ではなく所得です。

| BOOTHの年間売上 | 経費 | 所得 | 確定申告の目安 |
| ---: | ---: | ---: | --- |
| 5万円 | 2万円 | 3万円 | 所得税の確定申告は不要な可能性あり |
| 30万円 | 15万円 | 15万円 | 所得税の確定申告は不要な可能性あり |
| 50万円 | 20万円 | 30万円 | 確定申告が必要になる可能性あり |

ただし、医療費控除やふるさと納税などで確定申告をする場合は、副業所得も一緒に申告する必要があります。

また、住民税は別です。副業所得が20万円以下でも、住民税の申告が必要になる場合があります。

## BOOTH販売は雑所得？事業所得？

BOOTH販売の所得区分は、主に次のどちらかになることが多いです。

| 所得区分 | 目安 |
| --- | --- |
| 雑所得 | 趣味・副業として小規模に販売している |
| 事業所得 | 継続的に販売し、事業として運営している |

多くの人は、最初は「雑所得」として考えるケースが多いです。

ただし、販売を継続していて、売上規模が大きく、帳簿をつけて事業として運営している場合は、事業所得になる可能性もあります。

判断に迷う場合は、税務署や税理士に確認した方が安心です。

## BOOTH販売で経費にできるもの

BOOTH販売では、販売のために直接必要だった支出は経費にできる可能性があります。

たとえば、次のようなものです。

| 経費の例 | 内容 |
| --- | --- |
| 印刷代 | 同人誌、ポストカード、チラシなど |
| 材料費 | ハンドメイド作品の材料、パーツ、布、金具など |
| グッズ制作費 | アクリルキーホルダー、ステッカー、缶バッジなど |
| 梱包資材 | 封筒、OPP袋、緩衝材、段ボールなど |
| 送料 | 商品発送にかかった送料 |
| BOOTHのサービス利用料 | 販売時に差し引かれる手数料 |
| イラスト制作ソフト | Clip Studio Paint、Photoshopなど |
| フォント・素材代 | 販売物に使う素材、商用利用可能なフォントなど |
| 撮影用品 | 商品写真を撮るための背景紙、小物、ライトなど |
| 通信費の一部 | BOOTH管理や販売作業に使った分 |
| パソコン・タブレットの一部 | 販売作業に使っている場合 |

ポイントは、「販売のために使った」と説明できるかどうかです。

私用でも使っているものは、全額ではなく一部だけを経費にする考え方になります。

## BOOTHの手数料も経費にできる？

BOOTHで販売すると、サービス利用料がかかります。

このBOOTHのサービス利用料は、販売のために必要な費用なので、経費にできる可能性があります。

たとえば、ダウンロード商品の場合は、商品価格に対してサービス利用料がかかります。自宅から発送する商品の場合は、商品価格と送料をもとにサービス利用料が計算されます。

売上管理画面や振込明細を確認し、手数料がわかるように記録しておくと安心です。

## ダウンロード販売でも税金はかかる？

イラスト素材、PDF、テンプレート、音声データなどのダウンロード販売でも、利益が出ていれば税金の対象になります。

「物を発送していないから税金は関係ない」というわけではありません。

ダウンロード販売でも、次のような費用は経費になる可能性があります。

- 制作ソフト代
- 素材代
- フォント代
- BOOTHのサービス利用料
- 販売ページ作成に使った画像制作費
- 販売作業に使う通信費の一部

デジタル商品は在庫や送料が少ない分、利益が残りやすいことがあります。売上が増えてきたら、早めに記録をつけておくのがおすすめです。

## 趣味で売っているだけでも申告は必要？

「趣味で作ったものを少し売っているだけ」という場合でも、利益が出ていれば申告が必要になることがあります。

ただし、家にある不要品をたまに売っただけの場合とは考え方が違います。

BOOTHで作品やグッズを作って販売している場合は、販売目的の活動と見られることがあります。

特に次のような場合は、税金の対象として考えた方がよいです。

- 継続して販売している
- 利益が出ている
- SNSやpixivで宣伝している
- 新作を定期的に出している
- BOOTHから毎年入金がある

金額が小さいうちは大きな負担にならないこともありますが、記録だけは残しておくと後で困りにくいです。

## BOOTH販売で住民税に注意

会社員の場合、副業所得が20万円以下なら所得税の確定申告が不要になるケースがあります。

しかし、住民税は別です。

副業所得がある場合、住民税の申告が必要になることがあります。

また、会社に副業を知られたくない人は、住民税の納付方法にも注意が必要です。自治体によって扱いが異なるため、不安な場合は住んでいる市区町村に確認しましょう。

## BOOTH販売でインボイス登録は必要？

BOOTHで販売している個人が、必ずインボイス登録しなければならないわけではありません。

特に、個人向けに同人誌やグッズ、デジタル商品を販売している場合は、インボイス登録が不要なケースも多いです。

一方で、法人や事業者向けに素材、テンプレート、商用データなどを販売している場合は、取引先からインボイス対応を求められる可能性があります。

ただし、インボイス登録をすると、消費税の申告が関係してくることがあります。

副業規模が小さいうちは、勢いで登録せず、必要性を確認してから判断した方が安全です。

## BOOTH販売で残しておきたい記録

BOOTH販売をしている人は、次の記録を残しておくと確定申告のときに楽になります。

| 残すもの | 理由 |
| --- | --- |
| BOOTHの売上明細 | 年間売上を確認するため |
| 振込明細 | 実際に入金された金額を確認するため |
| 手数料の記録 | 経費として整理するため |
| 印刷代・制作費の領収書 | 経費の証拠になるため |
| 梱包資材や送料の記録 | 発送費用を計算するため |
| 素材・ソフト代の領収書 | 制作費として確認するため |

最初から完璧な帳簿を作ろうとすると大変です。

まずは、売上と経費がわかる資料を月ごとに保存するだけでも十分に意味があります。

## BOOTH販売の税金でよくある勘違い

### 売上が20万円以下なら何もしなくていい？

正確には、20万円で見るのは売上ではなく所得です。

また、所得税の確定申告が不要でも、住民税の申告が必要になる場合があります。

### 趣味だから税金は関係ない？

趣味でも、継続して販売して利益が出ていれば、税金の対象になることがあります。

### BOOTHから振り込まれた金額だけ見ればいい？

振込額だけでは、売上や手数料の内訳がわかりにくいことがあります。

売上、手数料、送料、経費を分けて確認しましょう。

### 赤字なら申告しなくていい？

雑所得の場合、赤字の扱いには制限があります。

他の所得と自由に相殺できるとは限らないため、赤字でも記録は残しておくと安心です。

## BOOTH販売を始めたらやること

BOOTH販売で利益が出始めたら、次の流れで整理しましょう。

1. BOOTHの売上を月ごとに確認する
2. 印刷代、材料費、送料、手数料を記録する
3. 年間の所得を計算する
4. 所得が20万円を超えるか確認する
5. 住民税の申告が必要か自治体の情報を確認する
6. 売上が増えてきたら会計ソフトや税理士相談も検討する

いきなり難しい帳簿を作る必要はありません。

まずは、売上と経費を分けてメモするところから始めるのがおすすめです。

## まとめ

BOOTH販売は、趣味に近い活動でも、利益が出ていれば税金の対象になることがあります。

特に会社員の場合は、BOOTH販売の所得が年間20万円を超えると、確定申告が必要になる可能性があります。

ただし、20万円は売上ではなく所得で判断します。

```text
売上 − 経費 = 所得
```

印刷代、材料費、送料、梱包資材、BOOTHのサービス利用料などは、経費にできる可能性があります。

まずは、売上明細や領収書を保存し、月ごとに売上と経費を整理するところから始めましょう。
